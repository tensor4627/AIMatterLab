# v0.3：服务商登录、任务工具双视角与布局

更新日期：2026-10-05。便携程序：release/GPU Sampling Studio 0.3.0.exe。

## 功能

Agent 顶部增加 Codex / Kimi / Qwen 选择及“登录 / 账户”。Codex 使用官方 ChatGPT 浏览器登录；Kimi 使用官方设备授权，支持中国大陆和国际账户；Qwen 支持 Coding Plan 或按量 API 的中国大陆与国际端点。Qwen 当前不提供新用户旧 OAuth 免费登录入口，见 [官方认证文档](https://qwenlm.github.io/qwen-code-docs/en/users/configuration/auth/)。

Kimi Code **2.1.1** 与 Qwen Code **0.24.7** 官方 CLI 随程序打包，通过 ACP **1** 接入。各服务商使用本应用独立配置和会话索引；切换服务商不混用历史，不修改全局 CLI 配置。Qwen 密钥在主进程通过 Electron safeStorage / Windows 用户凭据保护加密落盘，不进入设置 JSON、命令参数或公开账户返回值。Kimi 授权凭据由官方 CLI 保存在本应用私有配置目录中。

模型目录、思考选项和上下文来自实际协议回报。Codex 保留 effort 和可编辑预算；Kimi / Qwen 仅展示协议支持的思考选项，其上下文预算修改目前禁用。目录中的模型配置不等于账户有访问权限；真实回合得到模型输出前显示“模型调用尚未验证”。

首页改为七类任务卡，左侧工具分为 MD、训练、主动学习、pyGAS、资产请求、Viewer、队列监视。工具页反向展示其参与的任务；关系和可选流程见 [工具生态与任务关系](architecture-workflows.md)。任务计划支持核心步骤、可选步骤、用户已有输入、保存与交给 Agent 准备。

设置新增“工作区布局”：Agent 可在中间大窗，任务标签在右侧；也可以保留原布局。切换保留输入和组件状态。

## 执行边界

所有服务商均通过科学 MCP 创建草稿；计算验证与提交仍由用户在模块页点击执行。Kimi 使用固定工具启用表；Qwen bare 模式会忽略 core-tools，因而本版使用显式 exclude-tools，并核查实际模型请求只包含科学 MCP。ACP 的客户端文件、终端和非科学执行权限一律拒绝。Qwen 首次会话通过官方 session/resources 状态扩展等待 MCP 完成发现并连接，失败停止会话准备。

计划不是自动工作流调度器。NEB、TorchNEP、NEPMaker、ActiveMiao、外部 DFT、OVITO 和集群调度当前明确标为待接入。保存请求草稿不会启动外部计算。
