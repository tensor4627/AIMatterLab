## 已实现

- 一个会话绑定一个持续更新的计算流程。可在同页手填或由 Agent 更新，实际文件与参数一起审阅；保留项目、会话、计算环境、工具和任务两种导航。
- 技能地图按功能、阶段、来源、依赖及提供方共享范围加载。普通计算复用真实环境探测后的运行时路径和版本信息；安装指南不随每次计算重复附加。教程规则标明中文/英文获取状态和实际源码版本，参考资料不等于可运行适配器。
- pyGAS 组合器使用注册源码中的 CV/Bias/Switch/Neighbor 类名、构造参数、类型、默认表达式、连接及固定输出维度。PLUMED 示例必须核对公式、单位、原子编号、PBC 和归约；不通过原生力钩子绕过 pyGAS。
- 当前会话拥有 canonical 图和框架生成源码；两文件与 journal 使用 CAS 并读回。迟到返回、外部改单文件或图维度变化不会恢复旧复核或覆盖新会话。
- 库外 CV 先讨论并由用户确认公式，再确定性生成 primitive，进行单独代码审阅和有界 CPU 数值检查。私有库单独使用 Git，位于 ignored 运行目录，不修改引擎仓库。数值和序列化验证按定义、参数、结构及环境哈希绑定；物理适用性另行验证。
- 私有定义的提供方读取按当前精确版本单独授权，默认不包含历史、运行结果或其他文件。撤销在返回前再次校验。本地查看、编辑及人工复核不依赖模型分享。
- 同一流程支持实际产物选择、复制读回、GPUMD 原生参数编辑、六类实际输入核对、本地科学输入复核和独立目标身份确认。准备、验证、提交分开，提交前重新检查快照、版本、完整运行时身份与资源范围；未知运行只核对、不自动重提。
- 已有计算项目可在界面编辑授权，展示逐字段变更。项目 ID 不可编辑，未知字段保留，提交前核对最新完整记录；取消不写入，草稿工作区不能由此升级为计算项目。使用现有主进程授权接口，MCP 权限不扩大。

## 限制与兼容性

首版仍为 1.0 前开发版本。必要的界面整合可调整，SSH、凭据、环境、项目授权及真实运行状态继续保护。本代未对科学引擎分支或源码作修改。

当前私有部署路线限已审阅的固定标量 TorchScript/GPUMD 契约；私有混合、OPES、AOTI 等未审路线明确 blocked，不自动降级。短例不覆盖所有原子、生产规模、长时间稳定性、严格 restart parity、相区分或自由能收敛。缺失 Materials Project API key 的真实查询、新账户调用、未登记集群和未实现训练/主动学习适配器按 blocked/not_run 处理。安装包、第五轮及最终联合界面验收未完成前，不建立发布标签。
