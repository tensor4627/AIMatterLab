# v0.18.7 · 应用账号、流程恢复与文件工作区

日期：2026-10-29。本代将账号配置从对话移到应用层，修复 DeepSeek 工具参数与重启恢复问题，并整理流程中的文件展示和工作区管理。

## 用户可见变化

- 左侧搜索下方新增「账号与 API」。Codex、Kimi、Qwen、DeepSeek 和自定义 API 在此统一配置；同一服务商的会话共用登录。配置账号不创建会话，不绑定计算项目，也不切换当前对话。未登录时给出此入口并保留未发送文字。支持连接测试、刷新状态，以及确认后移除凭据；退出 Codex 会说明对本机共享登录的影响。
- 对话列表使用本地语义规则生成简称，可在省略号菜单中重命名、删除。手动名称优先，恢复不会替换流程标识。简称生成没有额外隐藏模型调用。
- 「配置部署」可在参数尚未齐全时打开，提前设置目标、队列和资源。准备、复核和执行仍检查参数保存、当前版本审阅、工作区选择及实际输入快照；不能因按钮能导航就执行旧输入。页面显示具体的就绪原因。
- 流程摘要显示文件名和数量，完整路径收进详情；单个输入以文件卡片展示，可预览、修改路径或移除。兼容旧 `files` 列表字段，数值列表保持原类型。支持选择文件及折叠的手输路径入口。
- 尚未选择工作区的新流程先询问「新建工作区 / 使用已有工作区 / 沿用草稿目录」；已明确选择的同一作业服务工作区可供后续会话复用。选择之前不自动复制外部输入。工作区采用 WSL 作业服务管理的目录，可选择复制或软链接，按内容与导入方式复用资产；导入文件和将它用于当前流程是明确的两个操作。

标准工作区布局如下。原草稿、实际作业及已登记计算环境保留；不会把已有项目整体复制或搬迁。

```text
assets/structures/    assets/models/    datasets/
pygas/definitions/   pygas/biases/      pygas/analysis/
pydyn/inputs/        pydyn/runs/
gpumd/inputs/        gpumd/runs/
nep/training/        nep/evaluation/
hotpp/training/      hotpp/evaluation/
torchnep/training/   reports/
```

这是输入整理布局；实际计算目录仍由 worker 的运行记录管理，不宣称旧作业已迁入这些空目录。已有输入可继续引用原位置。软链接仅登记明确选中的源文件，不授予整个源目录；源文件变化或链接失效需要重新检查。正式运行始终生成独立输入快照，修改原文件、重定向链接不能改变已准备的快照。命名工作区本身没有引擎执行授权。

## 协议和 API

- Codex 固定对齐本机实际安装的 `0.165.0-alpha.1.2`，由该 CLI 重新生成 TypeScript 协议。保留初始化、流式事件、动态模型/Effort、原会话恢复及审批边界。版本不匹配时明确报告预期与实际版本，避免悄悄套用旧协议。客户端版本来自应用 package.json。[官方 app-server 文档](https://learn.chatgpt.com/docs/app-server)
- DeepSeek 的 `present_task` 模型可见 schema 使用步骤对象；格式错误返回具体索引、缺项和正确示例，要求本轮修正原 task_id，不自动补科学数值或新建流程。原先笼统的 `Invalid arguments.steps[]` 属于工具格式错误，不是登录失败。
- 实机重启测试发现：待恢复的 DeepSeek 对话在 `model/list` 之前自动恢复，导致模型目录尚未加载就拒绝已有模型。本代让目录读取独立完成，冷进程显式恢复时也先取得目录；不会因此重放上一轮请求。
- 自定义 API 支持指定 Base URL、模型 ID、加密密钥和服务名称，使用 OpenAI 兼容 Chat Completions、SSE、function/tool_calls。HTTPS 为默认要求，回环地址可使用 HTTP；拒绝带凭据、查询串和错误接口后缀的地址。模型登记和实际调用验证分开。
- 自定义 API 不发送 DeepSeek 专用 thinking/reasoning 参数，历史与事件使用独立命名空间。更换服务地址不能向新地址续发旧历史。公开软件指南需单独勾选；未继承四个内置服务商的共享范围。私有 CV 仍有独立共享检查。
- 兼容接口不代表任意第三方原生协议；Anthropic Messages、Gemini 原生接口、Responses-only 和各厂商独有认证/推理参数不在本代支持范围。DeepSeek 使用官方函数调用接口，未启用其 beta strict 模式。[DeepSeek 官方工具调用文档](https://api-docs.deepseek.com/guides/tool_calls/)
