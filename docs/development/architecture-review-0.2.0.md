# Gemini 架构建议与 AIMatterLab 0.2.0 源码核对

评估对象为针对 v0.1.31 撰写的架构报告 `aimatterlab_v0_1_31.html` 和后续交互方案 `aimatterlab_9_3.html`。复核基线是本地 `48d286e`，其 `package.json` 为 0.2.0。优先处理能从用户入口复现、会影响用户判断或操作对象的问题。四位 GPT‑6.2 Sol Max 子智能体参与开发和独立复核，主审合并检查工作树并单独运行定向验收。

| 工作包 | 决定 | 0.2.0 的依据与处理 |
| --- | --- | --- |
| M1 交互缺陷 | 采纳六项明细 | 任务页将工具组返回按钮接到了打开运行的回调。资源台刷新异常会清空快照。主力 SSH 面板写死配色和字号。设置空闲时长读入 NaN。清除损坏续算记录使用原生确认。资源工具的三个 JSON 框共用难以定位的错误。六项均有对应修改。报告总览所说的十项缺陷缺少十条独立的复现与验收记录。 |
| M2 工作台拆分 | 采纳布局边界 | 基线 App 直接调用 99 次 `useState`，已有会话选择、工具组定位和资源观察模块。本轮把栏宽、显隐、底栏和窗口宽度收至 `useWorkspaceLayout`，保留会话与资源页的独立偏好和旧值恢复。Hook 仍由 App 调用；拖栏时 App 仍会渲染。Worker 重连、授权编辑与引导有各自的身份和恢复条件，可以按以后实际变更逐项拆出。 |
| M3 对话拆分 | 采纳草稿与消息列表的渲染隔离 | 基线 Agent 有 57 个 state 和 69 个 ref，已有 `ConversationMessages` 和使用 `memo` 的 `ChatMessage`。草稿每次改变时，父组件仍新建书签集合、列表仍遍历历史。现复用书签数组，对消息列表做浅比较。附件与跟进队列的刷新计数器确实存在；替换前须覆盖并发发送、跨会话编辑与恢复的原有语义。 |
| M4 终端与算力资源 | 采纳外观共享，保留终端分工 | v2 登录与 Shell 以及兼容终端现在读取同一主题和字号设置。WSL、未指定 v2 profile 的入口及 plain SSH 仍由旧面板承接，认证输入和共享 Shell 有各自的读写生命周期。主进程已有服务连接、托管持久化、授权和用户意图模块。发布、恢复、释放共同维护资源实例和租约；本轮保留这个所有者。 |
| M5 集群观察与配置 | 采纳按页面和作业状态观察，区分空资源上限与零 | 终态详情停止定时读，断线/隐藏期间暂停；手动核对、原服务恢复和活动监视页发现新作业继续可用。SSH 字段已有显示开关，保留默认遮罩。后续交互方案进一步落实环境键值表单，可在两个配置入口继续同一草稿，保留高级 JSON。Worker 的 profile/队列纯校验与提交脚本渲染可独立拆出；传输、查状态和撤销涉及原连接快照、共享预算、锁顺序与提交回执，暂缓整体拆分。 |
| M6 语言、存储与层级 | 采纳对用户有影响的部分 | 工作台布局、当前页、流程图折叠及语言缓存容许浏览器存储失败。设置预览可即时切换、Esc 可恢复。基线已实现取消回滚，原缺口是工作流和队列子组件直接从存储重新猜语言。现从同一运行时值取语言，并修正运行列表的日期区域和服务端口提示。浮层统一指定菜单、弹窗、版本提醒、诊断提示与帮助的顺序。PyGAS、CV 和向导已有显式语言参数，整体迁移字典保留为单独工作。 |
| M7 可视化与工具登记 | 采纳 | Three.js 按场景复用求中心和位移的向量、变换矩阵，按元素复用颜色。ECharts 同帧合并 resize，刻度数变化时才重写坐标轴，卸载时取消待执行帧。工具表单区分 JSON 字段、语法和顶层类型。实际 App 已按资源等信息重挂面板；补齐面板自身的资源版本边界，避免较早查询覆盖较新配置回执。 |
| M8 工程护栏 | 采纳行为回归，延期全库规则 | 用实际点击、键盘、迟到回执、调用次数和隔离状态验收。选定的布局测试还修正了已失效的侧栏选择器。全库重排、固定行数或 Hook 数量门禁，以及按日期退役旧终端，缺少与本次缺陷相称的收益。 |

## 影响决策的三处实现细节

- **观察与执行的成本不同。** `GET /api/cluster-runs` 从 Worker 存储列出作业，详情自动读取的是 `/api/cluster/observation`；老服务可从作业列表按 ID 回读。显式核对状态和日志才调用 `/status` 和 `/log`。托管 Worker 的 HTTP 可能经现有 SSH 隧道。因此能验证的是页面少发了多少次读取。报告中的“每分钟六次登录节点查询”缺少这层区分。[Worker 路由](../../backend/worker/studio_worker/transport/routes.py) · [集群页面](../../frontend/features/cluster/ClusterPage.tsx)
- **持久化失败有两种后果。** 布局写失败时，窗口仍可用内存中的栏宽。续算请求若未能保存幂等键，发出请求会失去恢复依据。后者继续暴露错误。清理损坏记录要核对当前运行身份和缓存原文，Esc、换页、隐藏工作区及旧确认失效均有专门用例。[显示偏好](../../frontend/ui/preference-storage.ts) · [运行详情](../../frontend/features/runs/RunDetail.tsx)
- **文件长度不能替代性能实测。** 120 条合成消息的用例直接统计列表遍历，250 条历史消息的用例检查选区、滚动和已完成消息的 DOM。图表和结构用例检查同帧调用合并、对象身份、相机与显示数据。报告预测的 90% 堆分配下降、十万原子帧率、评分 8.8 和六周工期均未测定。[聊天回归](../../scripts/frontend-chat-experience-cases.mjs) · [可视化回归](../../scripts/frontend-visualization-experience-cases.mjs)

## 后续前端与交互方案

| 建议 | 决定 | 用户可观察的变化与取舍 |
| --- | --- | --- |
| F1 工作台与对话状态拆分 | 部分采纳 | 布局偏好独立管理，历史列表在草稿变化时可跳过遍历。保留已有任务恢复、会话选择和消息发送的职责边界。减少 75% 的根状态本身无法证明恢复、发送或输入更可靠。 |
| F2 常用配置表单化 | 采纳 | 集群环境可以逐项编辑可执行文件、库和变量。续算按所选引擎填写实际 checkpoint、脚本或配置路径。资源工具支持逐项参数、输入输出端口和常见最小测试设置。三个入口保留高级 JSON，缺项、坏文本及未知的提交结果可回到原入口处理。 |
| F3 长会话与日志 | 修复实测问题，延期整表虚拟化 | 聊天每次读 30 回合，用户主动加载的旧页仍会挂载。250 条消息用例验证选区和阅读锚点。运行日志按读取批次显示，未超限的 20,000 行夹具只有一个文本块。另一个超过 1,048,576 个 UTF-16 码元的夹具证实整块淘汰会造成阅读上下文丢失，修正为只裁去超限前缀。持续展开超长历史的性能仍值得单独测量。 |
| F4 双主题与字号 | 采纳具体缺口 | 登录终端、共享 Shell、兼容终端随外观设置更新；晶胞线实时换色并保留相机；作业产物 Monaco 预览支持主题、字号放大与 12px 下限。局部可达性由相应入口用例覆盖，全组件零截断尚无测量。 |
| F5 浮层、语言、分包 | 修复冲突，沿用现有懒加载 | 修正语言预览来源和浮层遮挡。生产构建的入口 HTML 只有一个 JS 和一个 CSS。实际静态依赖闭包及源码映射均未包含 Monaco、Three.js、ECharts/zrender、PDF.js，四条动态导入可追到对应用户入口。无额外 `manualChunks` 改动。此次未测冷启动耗时。 |
| U1 首屏摘要与快捷入口 | 采纳 | 流程图下方展示可追溯的目标产物、结构、模型和采样参数。已知缺项可直接定位字段，未定位的待确认事项有独立入口。工具详情可固定到侧栏和工具目录，窄屏可从目录打开。会话归档、筛选和正文搜索在基线已有入口。 |
| U2 PyGAS 端口与排序 | 采纳契约可支持的交互 | 展开节点的端口面板可查看来源、目标和已知张量阶数，选接前可见 0D 冲突；未知阶数保留待确认。Collect 顺序支持鼠标拖动、按钮及键盘，沿用已有偏置参数置换校验。保留下拉入口。自由布局的全屏节点画布留待真实图规模与使用需求验证。 |
| U3 资源快照、集群引导 | 采纳快照、停读和可选引导 | 资源读取失败时保留带时间的旧快照。终态详情停止自动查询，活动监视页仍能发现新作业，显式核对可重试。保留已有逐步引导、可单独进入的配置标签、显式显示 SSH 信息和将脱敏诊断交给 Agent 的入口。强制单向配置会妨碍已登记用户只修改队列或环境。 |
| U4 交互缺陷与安全存储 | 采纳可复现缺陷 | 工具组返回、空数值、续算确认、显示偏好读取和语言预览均从实际入口验收。持久化幂等键失败时阻止发送，避免未知请求重复。 |
| U5 拖动、视口和窄屏焦点 | 采纳 | 图表合并同帧缩放，原子变换复用临时对象。窄屏显式切换工作区与对话时返回原可见控件，保留草稿光标和工作区滚动位置。终端仍由工作区底栏进入。未在万原子硬件场景测量帧率。 |

两份报告提出的 8.8、9.3 分和各模块涨分缺少可重复的打分样本。验收按发生了什么、从哪个入口观察、哪些结果仍未验证记录。[0.2.0 开发与验收记录](../releases/aimatterlab-0.2.0.md)
