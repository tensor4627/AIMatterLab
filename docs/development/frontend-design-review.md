# 桌面工作台前端设计评审与实施计划

评审基线为 `eea5bbb`。使用场景是研究者一边看文件、参数或运行记录，一边与 Agent 讨论。三栏同时打开时，中间面板往往比普通网页窄得多。布局应按面板可用宽度组织，首屏优先交代用户正在处理的对象、它的真实状态以及可以采取的下一步。[软件规范](../software-specification.md) · [先前的文案清单](frontend-copy-simplification.md)

## 美术方向与交互约定

沿用石墨灰与淡紫。把《明日方舟》平面设计中图文分区、清晰的索引和对齐关系转译为工作台的导航、分隔线与数据列表。淡紫留给选择、焦点和主操作，错误及等待沿用各自的文字和状态符号。长文、代码和科学图表需要稳定的背景。[鹰角《明日方舟》](https://ak.hypergryph.com/)

借鉴 iOS 让动效解释操作结果的做法。导航框架保持稳定，在新内容或浮层出现的位置使用短距离、快速减速的过渡。连续打字、流式输出、缩放图和调整栏宽时应能立即操作。系统开启减少动态效果时，信息与操作仍完整可用。[Apple 动效指南](https://developer.apple.com/design/human-interface-guidelines/motion)

## 分区评审与实施清单

| 区块与源码入口 | 批评与使用后果 | 设计与验收要点 |
| --- | --- | --- |
| 桌面框架、导航与布局菜单 · App | 侧栏导航、新建动作、顶栏的面板按钮都占用强调色。三栏下多个同等重量的焦点分散注意力。 | 用稳定的选中标识、区块间距和表面明度交代位置。窄窗检查工作区、Agent 和终端切换。 |
| 首页与最近记录 · App | 任务入口、统计解释和最近项目争夺垂直空间，用户要先扫过固定文字才能找到自己的记录。 | 让继续工作、真实记录与下一步操作先进入视线。统计只突出名称与观测值，未知值清楚标示。 |
| 对话、活动与输入框 · Agent、ChatMessage、ToolActivity | 空状态的介绍和输入提示重复。工具事件与长回复在窄栏里容易形成连续灰块。 | 空态让出空间给输入，区分发言、活动和待回答问题。保留审批对象、失败原因、消息位置和未发送草稿。 |
| 设置、模型账号与更新 · SettingsPage、ProviderLogin | 通用分类介绍和 API 实现介绍拉长设置表单，配置后果却混在普通说明里。 | 以标签、当前值、保存入口为骨架。把字段背景放在字段旁帮助，授权范围、密钥沿用条件、重新连接及更新进度常显。 |
| 首次设置与课节 · SetupAssistant、SetupLesson | 分步行动与教学段落并排时，当前该点击的位置容易被淹没。 | 强调当前步、真实完成条件和继续或稍后入口，补充原理按需阅读。 |
| 算力选择、SSH 与终端 · ComputeResourceConsole、SshConnectionPanel、SharedTerminalPanel | 资源、通道和服务容易因重复卡框被读成同一状态。说明占用终端可视行。 | 分开资源身份、连接回执及下一步。登录输入、目标路径、断连恢复与最后一行输出始终可达。 |
| 项目授权、环境、集群队列与文件 · ProjectAuthorizationForm、ComputeEnvironments、ClusterPage | 检查机制和资源事实同列时，很难判断哪些环境真正可用。 | 以环境身份、实测状态、队列与动作排列。说明贴近检查项，授权范围、写入后果和失败保持可见。 |
| 科学工具、技能与工具包 · SkillsWorkbench、ToolPackagesPanel | 卡片同时解释模块、能力和实现，找工具要反复读段落。 | 目录首先回答可用工具和入口。展开后核对声明、版本和测试范围。公开分享及私有资料范围随选项显示。 |
| 流程图、阶段与执行 · AgentTaskPage、WorkflowRoadmap、TaskStageEditor | 图、编辑表单、复核面板的多层标题和边框切碎一项任务。 | 维持流程图和任务标题的固定关系，用清楚的段落层级组织下一步、缺项与参数；来源和提交身份可核对。 |
| 工作区文件、目标与部署 · WorkspacePanel、ConsumerStageEditor、DeploymentPanel | 目录规则等背景挤占当前选择和待导入文件的空间。 | 把规则解释移到选项帮助，保留实际采用值、待办、输入快照和执行目标。 |
| PyGAS 与自定义 CV · PygasComposer、CustomCvWorkbench | 组合器同时承担对象排序、编辑和数值核对，若每一行常驻操作说明，关键参数离开视野。 | 压缩可重复的控件解释，保持单位、排序、依赖与数值核对结论。 |
| 资产、结构、文件编辑与可视化 · AssetInspector、StructureBuilder、ui/heavy | 源码执行原理、结构生成流程的介绍重复工具名。科学来源和采样限制更值得占据画布旁的空间。 | 将实现背景置于帮助。文件名、保存状态、元素及标签、预览截断与参考假设就近显示。 |

| 弹窗、参数标签、悬停说明与反馈 · Dialogs、Tooltip、ParameterFields、Notice | 逐项加问号或仅使用浏览器 title 都会损害可发现性。浮层还可能被面板裁切。 | 优先复用已有字段或按钮作为触发器，独立说明要能键盘访问。检查悬停、聚焦、Esc、越界及缩放；错误和必填条件继续就地显示。 |

## 开发顺序与分工

1. 桌面与会话组负责 App、导航、首页、对话、主要视觉变量、公共样式和过渡节奏。
2. 资源与设置组负责设置账号、首次引导、算力、集群和终端。逐项识别影响用户决策的说明，结合表单和连接状态重排。
3. 科学工作区组负责工具目录、流程、PyGAS、CV、资产及运行面板。按当前对象、必需输入、执行结果组织密集内容。
4. 主审负责跨区共用提示组件、双语一致性与集成验收。先核对实际差异和类型，再用隔离 Electron 窗口检查主要入口、二级说明、窄屏、字号、深浅主题和减少动效。原始截图和运行回执放在忽略目录。

## 对具体界面的取舍

- **会话侧栏与命令搜索。** 在改版前 1366×768 的深色实拍中，底部「设置」和「检查更新」各自断成两行，而搜索框已经写明快捷键。底部工具适合使用带有可访问名称的图标。组名、会话名和所连资源是用户自己的数据，应优先占据行宽，完整名称须可查。
- **首次设置。** 铜晶胞让研究者直接识别材料建模软件，拖动和复位具有可观察结果，值得保留。步骤名称应能一眼区分已完成与当前步。账号和算力页则要把当前服务商、连接状态、配置动作放在一起，跳过入口在各步骤使用同一位置。
- **普通聊天与规划。** 发送前最重要的是当前对话、正在编辑的内容以及这条消息是否启动规划。空态引导可以用可点击的草稿示例承担。对话选项适合容纳服务细节，遇到待授权、需回答的问题或准备失败时，应把对应操作带回输入区域。
- **SSH、终端和计算项目。** 区分「能登录」「已交接终端」「作业服务已核对」三件事。终端输出需留出最后一行。选择工作目录要能看到账号、主机、提交路径和实际确认结果；配置队列时，授权范围写在同一表单内。路径、回执或安全后果不应仅靠悬停才能读到。
- **工具详情、关系图与训练。** 目录中的模块用统一尺寸的图标、名称和进入标记即可辨认；详情页负责解释能力、接入范围及限制。训练和导出是不同动作，格式要求随导出入口提供。规划中、待接入的能力仍需要文字状态。
- **流程参数与执行。** 编辑区同时存在参数说明、默认值、来源以及操作回执。把原理附着在字段上，当前值、单位、有效默认值保留在输入旁。图节点可展开并定位缺项。长路径、命令和历史快照更适合可复制的展开区，尤其在大字号下。
- **PyGAS 和自定义 CV。** 节点排序、端口对应及数值边界需要同时对照。模块简介可以在类别名称或独立说明中查阅；数据精度、保存的默认值和版本适合折叠。顺序变化要求重新核验的状态要留在组合器内。私有代码的共享边界跟随实际操作呈现。
- **资产、晶体生成与图表。** 成功登记、结构几何通过和能量验证是三个不同结论。把登记回执的帧数、标签库存、来源哈希拆成可扫读的字段，详细回执供展开。结构图保留元素图例和总数，旋转、缩放手势放到画布旁的提示。曲线的非法行、截断和缺失值会影响读数，须随图显示。
- **作业来源、监视与诊断。** 未连接、有历史回执、刚完成同步，分别对应不同的可信范围。计数缺失显示未知。用户可以先按当前状态找到任务，再核对来源时间。错误摘要和恢复动作常显，原始诊断单独展开；回看未知提交应回到原尝试。
- **窄窗与字号。** 正常桌面入口曾把最小宽度设为 1100 像素，直接挡住规范要求的 1024 像素窗口。主窗口需能自然缩小，宽度不足时保留工作区与对话的显式切换。验收既要看文字是否折行，也要点击最后一行的操作，核对焦点、遮挡和滚动。

## 实拍后调整的设计

首页保留一个「新建计算」主按钮，已有记录可以直接进入；项目选择和账号入口移至各自的固定位置。数据资产页从资产检查与登记开始，已登记记录紧随其后，ASE 生成器和材料搜索排在后面。终端和远端目录可以独立滚动，窄栏中的保存操作回到文档流，避免遮住文件下载。

流程图根据节点列数决定初始缩放。短图优先让输入与产物在当前栏内同时可点，长图保留可读字号，通过平移、键盘和适应窗口查看全图。大字号时阶段进度可以换行，阶段操作跟随内容滚动。端点命中、正常与减少动画、悬停帮助及窄窗切换的实测结果见[桌面改版验收](../releases/aimatterlab-0.1.31.md)。
