# 共享终端与 SSH 入口

## AIMatterLab 0.1.1 会话终端

登录后点「交给 Agent」。已有对话时它接管当前终端，空白对话则在发出第一条消息时接管。随后在同一服务商、同一已认证连接切换对话，各对话使用单独的终端，切回来能继续使用原来的 shell。作业服务在同一登录连接上使用独立通道。

在「设置 → 计算连接」可修改空闲时长，默认 60 分钟。空闲回收结束对应 shell，再次使用时新开 shell；退出软件时关闭本次桌面创建的连接和终端。已经提交的调度作业继续由 worker 和调度系统维护。

## 分阶段接入与缓存（1.0.2-dev.9）

交互登录后仍复用同一条已认证 SSH，不依赖入口允许 TCP 转发。短单行 Python 启动器先报告实际条件，连接层和 worker 分别按完整内容哈希核验缓存，仅对缺失项做有界压缩传输。缓存存在不能跳过真实服务身份、健康、工具核验。连接层代码在 `desktop/platform/terminal-service/python`，以独立资源发布；修改它不改变 dev.8 的 worker 运行指纹或任务来源。

界面按后台真实阶段与收到的传输确认显示状态。首次 Python 无响应的有界超时不等于 Python 缺失；固定诊断只显示明确代码及经过校验的版本元组，不输出远端异常、路径或凭据。刷新是只读观察，不自动再次启动、安装、重连或重发。

取消按准确 session/attempt 执行。桌面桥先撤销本次准备票据，后台记住取消的启动 ID，阻止 POST 迟到后占用终端；不能只凭“当前没有通道”的快照宣布取消成功。STOP/失败退出与新的 shell 输出证明共同释放私有屏障。未确认恢复时，终端保持只读且阻止资源切换，用户可以继续只读刷新或明确关闭连接。自然退出也撤销工作流就绪状态，不能继续使用旧服务能力。

## 交互登录后的作业服务（1.0.2-dev.8）

交互登录可以承载正式作业服务。用户完成密码、验证码和主机确认后，明确点击“登录完成，连接作业服务”；桌面在原来的已认证 PTY 上传输固定且核验过的 worker 代码并建立私有请求通道，不另开 SSH 登录。服务器需要 Python 3.10 或更新版本，服务位于当前用户独立的 `~/.local/state/gpu-sampling-studio/ssh-services/<profile-id>`；不会安装、切换或更新科学引擎。

只有核对真实服务身份、运行资源指纹、健康和工作流工具后，当前 SSH 才成为任务编写与文件工作区。终端存活或 Agent 交接本身不等于服务已连接。服务启用后，输入、交接和尺寸变化被阻止，避免干扰私有协议；用户可明确返回交互终端。远端凭据只在远端使用，机器协议内容不进入普通终端回放。

用户可在当前连接配置同机 Slurm/LSF、科学可执行文件、运行和只读目录及资源上限；配置本身不授予项目/队列权限、不提交作业。正式计算保留项目授权、输入审阅与执行批准，登录节点不直接运行本地科学作业。任务保存稳定的 SSH 连接版本、服务器身份、worker 路径和资源指纹；断开或重开后要求明确连接原服务，不改用默认 WSL。提交结果未知时先核对已有回执，绝不自动重发。

正常退出仅关闭本次桌面的交互连接，远端服务和已提交调度作业独立存活。下面的“三个终端工具”路径仍适用于未启用作业服务的原始共享终端，不再作为所有交互 SSH 的固定能力上限。

dev.6 将打开或重新附加的 SSH 终端，按返回的准确连接版本和 session 绑定为当前计算资源。已登录会话会复用，不必退出重登；仍使用原有「交给 Agent / 我来操作」。未交接时可先建立会话身份并保留草稿，交接后再发送终端任务，不要求另外连接本地作业服务。

当前资源选择不会自动交接、重开终端或改变已有 worker、项目和作业。Agent 使用所选终端的独立 MCP；即使本地 worker 同时在线，也不抢占该资源路由。资源切换、人工接管、连接版本变化或终端退出后，旧权限不再视为就绪。通道运行不代表已验证 SSH 认证或科学计算结果。

## 交互路径

从 dev.40 起，侧栏、首页、计算环境页、Agent 的「连接计算资源」及设置中的主入口打开同一连接管理器。本地与集群配置可命名、保存多条并编辑；WSL 保存发行版、服务目录、端口及复用策略，SSH 保存明确用户、客户端、引用路径、路由与交互 / 密钥方式。必要字段直接展示，端口和路由等放入高级选项。用户名不从系统账户推断。

连接配置由桌面私有 SQLite 注册表管理，不依赖 WSL 才能保存或打开原生 SSH。配置有独立 ID 和版本；编辑不自动连接，不改变现有终端目标或计算任务绑定。打开前核对保存版本，配置变更会使旧 Agent 授权失效。已有 worker 内的集群配置保留在高级入口；新桌面 SSH 配置只表示登录连接，不自动生成调度器、引擎环境或正式集群部署。

WSL 连接先展示保存目标的审阅向导，由用户确认才接入。显式全局资源切换与旧任务的原来源恢复是两条不同意图：前者可切换当前接入，后者始终核对任务保存的原来源；任何连接选择都不重写任务、项目权限或作业状态。当前连接标记依据实际 worker 目标及连接观察，不从默认设置推断。

科学工具就绪与 SSH 终端存活分开显示；打开 SSH 不代表科学 MCP、队列或环境已就绪。密码、OTP 和主机指纹确认仍由用户在交互终端处理，保存配置不读取密钥或执行远程探测。

在「连接计算资源 / 设置 → SSH 集群」中选定并保存连接，用户名、客户端、密钥命名空间和路由来自该保存版本。页面提供「交互式登录」与「密钥自动登录」；未保存修改时禁用打开，避免使用旧用户名或旧路由。

从普通对话或窄屏打开登录时，先显示终端所在的内容区，再展开并聚焦底部面板；不能只改变隐藏子面板的展开状态。

交互式入口在底部终端面板打开同一 PTY：用户处理主机指纹、密码或二步验证码，再点击「交给 Agent」。Agent 通过三个结构化工具访问当前对话明确交出的会话，用户点击「我来操作」即可撤销其读写。认证输入和交接前输出不提供给 Agent。底部「本地终端」使用同一机制，适合先检查本地终端链路；它不是 WSL 连接或 GPU 环境验证。

点击「交给 Agent」即授予当前服务商、对话及所属流程对该终端的读写权限，无需再登记科学计算环境或重复共享。终端工具使用独立权限通道，不通过科学输入文件的分享过滤；未知工具和其他会话仍被拒绝。没有连接 WSL 时，桌面提供仅含三个终端工具的 loopback MCP，界面标为「共享终端可用」，不会显示科学工具已就绪。此时的普通消息不附加流程文件、参数或技能，计算输入复核仍需连接原作业服务。

从 `1.0.2-dev.2` 起，无需先发送消息或创建已保存对话：显式点击「交给 Agent」可连接所选服务商并建立真实空会话，再将现有终端交给它。未发送草稿保留；不自动发送模型消息、不重新登录 SSH，也不自动处理账号认证。失败时终端仍由人工操作；等待期间接管、关闭、切换会话或计算来源会使交接失效。

宽屏首次启动显示导航、内容和 Agent 三栏；普通聊天时终端保持可见，窄屏仍通过面板按钮切换。终端尺寸由实际可用区域计算，底部提示与状态行独占布局空间，调整字号和面板大小后最后一行输出仍须完整可见。

工具栏直接提供「断开连接」（SSH）或「关闭终端」（本地），一次点击关闭当前会话并立即撤销 Agent 权限；保留保存的连接和其他终端。无需再展开菜单或确认。正常关闭 AIMatterLab 会关闭本次桌面的交互终端，已提交计算作业独立存活。

密钥入口直接使用已保存的原生 SSH 客户端、用户、端口、密钥或 SSH-agent；Windows 与 WSL 路径保持各自命名空间。启用 BatchMode 和严格主机指纹检查，失败不自动转为密码登录。交互入口允许用户处理指纹确认。已有私有认证与隧道功能保留在高级选项，私有终端不会因新入口而自动共享。

## 生命周期与边界

Windows 原生 SSH 的子进程环境须保留已有 `ProgramData`；缺失时本机 OpenSSH 可在处理连接甚至版本查询前静默退出。只保留必要系统变量及已允许的 SSH-agent 引用，不转发 API token 或安装环境全量变量。注册表中的用户名与启动选项保持显式。

终端输入就绪以权威会话状态为准，不能等待辅助列表刷新后才暗中允许按键。前端 disableStdin 与输入处理器的权限条件须一致；隐藏、接管中、非人工所有、过期或退出时不接收输入，准备完成和点击区域时可聚焦。输入测试必须包含实际键盘事件以及真实PTY的独立字节回读，分别记录替身和原生边界，不能仅以固定输出和可见光标作为输入通过。

Agent 读取可传小的正整数 `max_bytes` 预算。传输以完整输出块分页，小于 16 KiB 时上取到 16 KiB，响应注明请求与实际分页预算；不能截断块后推进游标。下一页使用响应的 `cursor`，它是输出块序号。回归必须覆盖模型实际使用的 4096 / 6000 字节请求与连续读取，不只测省略预算的默认路径。此兼容发生在桌面桥，已有后台无需升级或重启。

主进程经 sender-validated IPC 管理独立本机 Node PTY daemon；renderer 无 Node、文件系统、任意命令启动接口或后台 capability token。daemon 初始化仅用一次 stdin JSONL；只监听 loopback，校验 Host、Origin 和随机能力令牌。描述符经系统凭据存储加密；运行目录在应用私有配置内，安装目录不写运行数据。从 `1.0.2-dev.5` 起，启动前从应用资源核对并发布稳定的 Electron-as-Node、服务和 PTY 完整闭包，按内容哈希分代；后台不再依赖会在便携桌面退出时被删除的临时目录。已发布代不自动清理，避免破坏存活终端。

从 `1.0.2-dev.6` 起，加密描述符使用版本 2 和每次桌面启动的唯一标识。旧 `broker.bin`、`brokers-v1.bin` 保持原字节，旧桌面会话和待确认尝试归为诊断历史，不探测、附加或操作旧后台，也不阻挡本次新连接。新桌面清除旧终端的界面资源选择，但不改注册环境、worker 来源或任务绑定。同一桌面中仍固定会话所属服务，并保留未确认打开保护和明确恢复入口；恢复入口不是 MCP 工具，不扩大 Agent 权限。

收起、分离、切换页面不会结束本次桌面的 PTY。正常退出会同步禁止新终端操作、撤销 Agent 交接，再有界等待本桌面自己的后台关闭交互式 SSH/本地终端；不会取消 worker 或调度器已提交作业。重开 AIMatterLab 后，由用户选择保存的配置建立新连接，不自动登录或重发命令。同桌面内状态不明的打开操作仍不会自动重试。强制结束进程、系统断电等异常退出不能保证已完成断开，下次启动仍不附加旧后台。

保存连接列表支持确认删除，只移除桌面保存项；不删除密钥、注册环境、授权或真实作业。当前桌面正在使用或打开的 SSH 保存项需先断开；WSL 保存项可以删除而不停止当前作业服务。删除采用准确版本检查，删除最后一个自动登记项后持久记录种子已使用，避免下次启动复活。未确认、取消和失败均不伪称删除成功。

每个后台最多四个会话，输出仅内存有限回放，输入请求有幂等标识和有界账本。交接变更 epoch 和回放起点；当前 provider / conversation / task 及原计算来源变化使旧工具请求失效。默认会话访问有效期 24 小时，过期停止操作但不自动杀进程；用户可显式结束。终端 daemon 不将命令及输出写入运行日志；交接后的工具读写会成为 Agent 会话上下文，可随服务商会话保存，不能据此宣称终端没有任何持久记录，也不作为完整任务审计。

运行状态只描述 PTY 进程，不把提示符、终端存活或 SSH 客户端退出推断成远程认证、命令成功、队列状态或科学有效性。共享终端不是项目授权、安装许可或提交许可；正式计算继续走原工作流审阅、作业服务和执行门。Agent 不能通过 MCP 新建终端、交接所有权或扩大授权。

任务规划开关与终端交接独立。每次消息和追加消息都携带当前开关，覆盖旧聊天/摘要中的状态；规划已开启时不得误报关闭。只有终端工具时可以讨论设计，但不具备正式工作流与科学文件编写工具；界面保留勾选并说明应由用户明确连接作业服务，不自动切换到其它 worker。开关也不是执行、安装、提交或项目授权。标准零字段 MCP 确认仅展示说明与接受/拒绝，有实际字段或未知格式时继续保留输入。

## 验证层次与后续工作

核心会话/HTTP、桌面桥的模拟测试与真实本地 ConPTY / Electron 界面分别记账。真实集群密码/OTP 登录、密钥登录、二步认证中断恢复、站点代理/隧道、调度器与计算节点验证须在用户选择的现场连接上另验，不能用本地 shell 或连接参数单测代替。

本轮只验证本地交互入口；不接管既有 SSH 原型、不探测队列、不提交集群作业、不重跑科学短例。具体通过与未运行结果见本代版本记录。
