# 持久共享终端与 SSH 入口

## 交互路径

从 dev.40 起，侧栏、首页、计算环境页、Agent 的「连接计算资源」及设置中的主入口打开同一连接管理器。本地与集群配置可命名、保存多条并编辑；WSL 保存发行版、服务目录、端口及复用策略，SSH 保存明确用户、客户端、引用路径、路由与交互 / 密钥方式。必要字段直接展示，端口和路由等放入高级选项。用户名不从系统账户推断。

连接配置由桌面私有 SQLite 注册表管理，不依赖 WSL 才能保存或打开原生 SSH。配置有独立 ID 和版本；编辑不自动连接，不改变现有终端目标或计算任务绑定。打开前核对保存版本，配置变更会使旧 Agent 授权失效。已有 worker 内的集群配置保留在高级入口；新桌面 SSH 配置只表示登录连接，不自动生成调度器、引擎环境或正式集群部署。

WSL 连接先展示保存目标的审阅向导，由用户确认才接入。显式全局资源切换与旧任务的原来源恢复是两条不同意图：前者可切换当前接入，后者始终核对任务保存的原来源；任何连接选择都不重写任务、项目权限或作业状态。当前连接标记依据实际 worker 目标及连接观察，不从默认设置推断。

科学工具就绪与 SSH 终端存活分开显示；打开 SSH 不代表科学 MCP、队列或环境已就绪。密码、OTP 和主机指纹确认仍由用户在交互终端处理，保存配置不读取密钥或执行远程探测。

在「连接计算资源 / 设置 → SSH 集群」中选定并保存连接，用户名、客户端、密钥命名空间和路由来自该保存版本。页面提供「交互式登录」与「密钥自动登录」；未保存修改时禁用打开，避免使用旧用户名或旧路由。

从普通对话或窄屏打开登录时，先显示终端所在的内容区，再展开并聚焦底部面板；不能只改变隐藏子面板的展开状态。

交互式入口在底部终端面板打开同一 PTY：用户处理主机指纹、密码或二步验证码，再点击「交给 Agent」。Agent 通过三个结构化工具访问当前对话明确交出的会话，用户点击「我来操作」即可撤销其读写。认证输入和交接前输出不提供给 Agent。底部「本地终端」使用同一机制，适合先检查本地终端链路；它不是 WSL 连接或 GPU 环境验证。

密钥入口直接使用已保存的原生 SSH 客户端、用户、端口、密钥或 SSH-agent；Windows 与 WSL 路径保持各自命名空间。启用 BatchMode 和严格主机指纹检查，失败不自动转为密码登录。交互入口允许用户处理指纹确认。已有私有认证与隧道功能保留在高级选项，私有终端不会因新入口而自动共享。

## 生命周期与边界

主进程经 sender-validated IPC 管理独立本机 Node PTY daemon；renderer 无 Node、文件系统、任意命令启动接口或后台 capability token。daemon 初始化仅用一次 stdin JSONL；只监听 loopback，校验 Host、Origin 和随机能力令牌。描述符经系统凭据存储加密；运行目录在应用私有配置内，PTY 依赖从只读应用资源解析，安装目录不写运行数据。

收起、分离、切换页面和正常关闭桌面不会结束 PTY。重开 Studio 核对原 daemon 身份后恢复已有会话列表，旧 Agent 授权撤销；用户重新附加并交接。未知 daemon 或未确认的打开操作不会自动启动第二条 SSH。只有「结束会话」明确关闭该终端进程；系统停止和后台进程退出不保证恢复 SSH。

每个后台最多四个会话，输出仅内存有限回放，输入请求有幂等标识和有界账本。交接变更 epoch 和回放起点；当前 provider / conversation / task 及原计算来源变化使旧工具请求失效。默认会话访问有效期 24 小时，过期停止操作但不自动杀进程；用户可显式结束。命令及输出不记录到日志，终端不提供长期审计记录。

运行状态只描述 PTY 进程，不把提示符、终端存活或 SSH 客户端退出推断成远程认证、命令成功、队列状态或科学有效性。共享终端不是项目授权、安装许可或提交许可；正式计算继续走原工作流审阅、作业服务和执行门。Agent 不能通过 MCP 新建终端、交接所有权或扩大授权。

## 验证层次与后续工作

核心会话/HTTP、桌面桥的模拟测试与真实本地 ConPTY / Electron 界面分别记账。真实集群密码/OTP 登录、密钥登录、二步认证中断恢复、站点代理/隧道、调度器与计算节点验证须在用户选择的现场连接上另验，不能用本地 shell 或连接参数单测代替。

本轮只验证本地交互入口；不接管既有 SSH 原型、不探测队列、不提交集群作业、不重跑科学短例。具体通过与未运行结果见本代版本记录。
