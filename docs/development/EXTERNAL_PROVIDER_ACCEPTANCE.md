# 外部服务商验收

Codex、DeepSeek 已由用户自测确认；该记录不替代独立的模型调用证据。Kimi、Qwen 按用户决定交外部测试者验证，兼容 API 的具体服务与手填能力另行记录。下表初始均为 `not_run`，不得因界面已有入口而标为通过。

## 测试准备

使用独立测试配置和测试者自己的账号，仅使用公开文字和新建草稿。账号入口位于左侧“账号与 API”。参数规划需要按安装向导连接一个 Studio 作业服务；无需 GPU、科学引擎、势函数或集群。前置条件缺失时记录原因，先完成可用的账号及聊天检查。

先记录 Studio 版本、所测安装包或 ASAR 的 SHA-256（注明对象）、系统类型、服务商、接入方式、显示模型、effort 及测试时间。未知项写 `unknown`。不要记录账号标识、密钥、验证码、令牌、私有路径或连接信息。

本轮不准备、执行或提交计算，不安装科学引擎。采用测试者明确可用的模型及有界请求额度；没有相应账号或权限的项目保持待验。

## 最小测试顺序

| 项目 | 操作与判定 | 初始状态 |
| --- | --- | --- |
| 登录 | 从对应服务商入口正常登录，核对账号状态及退出前的错误反馈；无需移除真实凭据。 | not_run |
| 普通对话 | 新建会话发送“请仅回复：公开连接测试完成”，核对真实回复、结束状态和会话归属。 | not_run |
| 参数规划 | 开启任务规划，使用下方公开提示；应生成一个草稿，保留真实缺项，不能产生作业。 | not_run |
| 同流程续填 | 在同一会话要求只修改温度，核对任务身份、其余参数及缺项保留。 | not_run |
| 重启恢复 | 正常关闭并重开同一测试配置，核对会话、草稿及未发送输入；不自动重发状态不明的请求。 | not_run |
| 模型与 effort | 选择界面实际支持的一个组合，完成一次有界文字请求；没有可审证据时，请求是否采用该值写 unknown。无 effort 能力记 not_applicable。 | not_run |
| 错误反馈 | 记录自然发生的网络、额度、模型或登录错误，核对反馈及草稿保留；不通过撤销账号或消耗额度制造错误。 | not_run |
| 兼容 API 手填 | 有可用服务时手填其支持的模型名与推理强度，核对输入保存、模型发现不可用时的手动入口及一次有界请求；具体接口逐一记录。 | not_run |

公开规划提示：

> 仅创建一个 GPUMD MD 参数规划草稿：温度 300 K，时间步 1 fs，1000 步，每 100 步输出。尚未提供结构、势函数和计算环境，保留缺项。不要准备运行、执行、提交、安装或查找本机文件。

续填提示：

> 继续同一个任务，仅把温度从 300 K 改为 310 K；保持任务身份、其余参数和缺项，不执行计算。

普通聊天成功不代表规划工具可用；本地恢复不代表又完成了一次服务商请求。真实请求的结果与本地界面检查分别记录。
