# 开发人员的集群工具测试

在「设置 → Agent → 开发人员选项 → 高权限模式」中选择已托管的测试集群，核对账号和工作区路径，点击「保存设置」。默认选择为「关闭」。普通聊天和任务规划都能通过同一个测试入口访问该资源。选择保存在当前桌面工作区。

开发授权绑定本机登记的资源、核实的远端账号、主机与工作区。原资源重新登录后沿用同一选择。Agent 从计算资源清单的 `developerWorkspace` 字段识别当前测试目标，按资源 ID 申请本会话的终端，在工作区直接测试已安装的工具。在尚未指定计算项目的对话里，工具列表可返回该工作区已激活工具的名称、版本、输入和输出。通过作业服务管理的测试继续采用该服务的实际项目、队列和运行记录。

可确认在工作区内完成的文件变更走远端约束执行。普通的独立调度器测试使用冻结脚本和单次提交回执。写入或在工作区外执行、调度器的外部路径，以及远端无法约束影响范围的命令都显示实际操作供用户确认。关闭模式或更换测试目标时，桌面撤回原开发通道，同时重新核对正在等待确认的操作。模型的原生安全设置沿用所选服务商的配置。
