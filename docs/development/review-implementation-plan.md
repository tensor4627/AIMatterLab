# 全量代码复审实施与验收

本计划依据 2026-11-13 复审会话中可读取的工程问题、前端方案及最后的弱校验修订整理。较早建议中的强制逐步人工复核、组合全部验证后才能尝试，按最后修订替换为授权内持续执行。本文是实施和验收清单，不能代替对应版本的实际测试回执。

## 产品约束

操作许可、执行状态和检查发现分别建模。未检查、过期或失败的科学证据保持其真实值，允许用户及 Agent 在已有委托内运行、观察、修改和明确失败后重试。实际输入、环境和资源身份仍必须准确；未知提交核对原尝试，不能重放。序列化 bias 的真实加载及目标环境检查、显式 AOTI 不降级、worker 权威运行状态、renderer 隔离及项目授权边界保持有效。

前端沿用石墨灰和淡紫色、简洁导航、中心工作区及默认展开的右侧 Agent。历史、草稿、阅读位置及运行上下文应连续，错误提供实际修复入口，低频细节按需展开。

## 工作包

| P13 | 交互终端登录、首次服务部署、保存登记、后续复用及日常提交 | 真实登录会话和模型；不重传、不重登录冒充复用；作业独立存活 |
| P14 | 可复用科学组合及执行指导，区分文件交接与同进程依赖 | 真实固定势与序列化 bias、实际目标中的有界联合运行、失败修复与来源 |

## 完成条件

1. 同一明确委托覆盖修改、执行、真实错误、修复及新尝试；模型不能自己增加项目权限。
2. 未做 AI 复核、旧证据过期及未验证组合不再统一禁止执行，原检查记录保持真实。
3. 实际无法执行的请求返回准确错误；bias/AOTI 的必需加载和目标环境要求有独立验证。
4. 未确认消息或提交不重发；其他独立工作继续可用。
5. 旧 provider 轮次的迟到事件和工具结果不能进入新轮，取消无回应有明确状态。
6. 实时、持久化、恢复和导出使用一致的凭据清洗；正常科学数值保留。
7. 单条损坏数据不破坏正常列表，诊断与原始坏记录可追溯。
8. 取消意图在远端命令前持久化；只在实际观察到终态后显示已取消。
9. CPU 检查不保留 GPU；GPU 冲突和既有运行的资源语义仍正确。
10. 当前产物列表不为观察而全量哈希大型轨迹；固定快照的内容、大小和摘要一致。
11. 复现导出准确列出输入、日志、结果及缺失/截断范围。
12. 当前消息和历史重放完整一致；往返会话、收起助手与页面切换保留草稿和阅读状态。
13. 点击运行名称保留当前会话；关联流程/会话跳转是单独显式操作。
14. 旧运行继续使用固定输入，新一版草稿可编辑，未知尝试不导致重复执行。
15. 深浅主题、宽窄窗口和放大字号下主要操作可用，当前 warning、执行和科学状态可区分。
16. 关键 IPC 的错误请求在编译和运行时被拒绝，renderer 无特权访问。
17. 真实集群链路完成首次部署、后续登记复用、日常提交/观察/取消及桌面关闭后作业存活；各阶段留独立证据。
18. 完整 Node、worker、前端渲染、受影响原生交互及必要有界科学检查有新回执；失败、跳过、阻塞和未运行不能计为通过。

## 分工与证据

前端、后端与 Agent 交互分别实施，主线程更新规格、整合共享契约并复核最终界面和真实链路。另一个会话仍在处理集群连接时，不并行编辑或操纵该连接链路；待其完成后核对实际变更和运行状态再接手。

所有原始日志、截图、运行输入、私有连接与模型配置保留在 ignored runtime 目录。公开版本记录只写实际行为、命令和范围，不包含机器私有路径、凭据或连接详情。测试边界分别报告组件模拟、真实桌面、真实模型、真实集群及科学有效性；原证据按原来源使用，不更名冒充新运行。
