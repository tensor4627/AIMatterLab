# 前端常驻文案精简计划

日期：2026-11-11。范围是 AIMatterLab 前端文案与展示，不改变计算、权限、连接或任务状态逻辑。集群作业连接由并行任务处理，本计划不修改其交互流程。

## 本轮已实施

- 首页标题区只保留“计算工作区”和原有“新建计算”操作，移除英文装饰标题、口号与介绍段。
- Codex 版本差异首次发现时显示简短浮动警告，可关闭，8 秒后自动收起；当前本地配置记住已提示，重连、切换会话及重启不重复。隐藏面板不提前消耗首次提示。存储不可用时在当前渲染进程内去重。
- 版本核对和能力校验继续执行；真实连接/能力失败仍按原错误通道显示。主页和会话面板不再保留常驻版本差异横幅。

## 保留哪些信息

精简对象是反复出现的理念、宣传和实现说明。以下内容仍直接影响操作决策，应保留，必要时改成更短的具体句子：

- 未保存、读取失败、提交结果未知、不可自动重提及对应恢复操作。
- 实际脚本与参数可能不一致、执行前核对与确认。
- 文件/曲线只展示部分数据的真实限制。
- 数据库候选不等于模型兼容或相确认；结构假设、来源及尚未验证范围。
- 凭据/内容共享范围、授权选择及保存后生效等后果。

## 实施顺序与验证

第一批处理上述高优先级文案；第二批将中优先级说明移近实际操作或帮助；第三批整理低优先级复现/检查说明。每批只验证受影响组件和真实渲染、窄屏/中英文布局、错误仍可见及操作可达，不因此重跑科学引擎或现有作业。
