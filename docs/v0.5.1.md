# v0.5.1：前端正确性与交互修复

更新日期：2026-10-14。本代为源码补丁；package.json 与界面版本均为 0.5.1。未重新生成便携安装包，也未建立发布标签。

## 高优先级修复

- 集群轮询和 Agent 任务更新保留用户编辑的参数；内嵌运行状态继续查询 worker，不用计划状态冒充作业状态。过期状态、输入和产物响应不会覆盖新选择。
- 失联时，运行队列保留 unknown 项；统计显示未知，侧栏与状态栏一致，避免真实作业仍运行时显示空闲。
- 验证记录、引擎错误与退出信息分别展示。产物预览清空旧内容、显示加载/失败并只读，避免把用户修改的文本当作真实输出。
- 提交操作等待刷新并保留修订幂等键。提交响应丢失时切换到原修订任务状态核对，不生成新修订请求；不自动重提 unknown 作业。
- 未确认的续算草稿请求保存原参数和幂等键，跨页面和 renderer 重载保留；手动重试仍是同一草稿请求，成功后清除记录。记录损坏时阻止新建，续算参数必须为 JSON 对象。续算仍须审阅后执行。
- 新任务表单与 JSON 使用显式“应用 JSON”同步；JSON 未应用时阻止表单覆盖和草稿创建。资源默认值取当前项目授权的首个 GPU 和时长上限。
- Bias 仅发送当前家族字段，检查必填参数与两个不同的非负整数原子索引；每次生成独立构建文件，不覆盖已有文件。生成期间的编辑器新修改保留；更换已编辑输入来源前提示丢弃风险。

## 交互与视觉

修复中文 IME Enter 误发送、技能目录无法手工换行、设置关闭未回滚预览，以及 Runs 导航保留旧详情的问题。任务表格组件移至 App 外，避免每次刷新重挂载；搜索与命令面板独立。恢复不存在的页面时给出返回入口。服务商绑定仅在项目切换时应用；发送失败保留输入。未知审批类型不提供允许按钮。

弹窗增加对话框语义、可访问名称、文档级焦点约束、Escape 和焦点恢复，跳过隐藏/禁用控件。图表明确提示前 4000 行/最多 6 个数值列的预览范围，显示无数值数据状态；浅色主题调整文字、曲线和网格，并避免轴标题裁切。补齐聊天输入焦点轮廓、标签关闭目标尺寸、浅色状态对比度，并区分已验证与已完成。

## 保留边界

本轮不进行 App 大规模拆分、全量 IPC 类型体系迁移、bundle 拆分、WebGL 全面兼容或结构晶胞图层设计。既有 bundle 大小警告仍存在。浏览器 fixture 无法验证 Electron 主进程的真实输入法平台事件、屏幕阅读器、实际服务商网络异常和集群调度行为。导出疑点经主进程核对后排除：原实现只使用 run.id 从 worker 取真实记录，未修改该契约。
