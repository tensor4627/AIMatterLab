# v0.6.0：会话拥有流程与可视化参数审阅

更新日期：2026-10-14。保留已有 0.5.1 修复，增加持续更新的会话流程、步骤参数卡、AI 复核和项目对话导航。源码、文档和版本记录由 Git 管理，原始证据与安装包留在忽略目录；不自动推送。

## 会话与流程

每个 Codex / Kimi / Qwen 会话默认管理一个流程。同一会话继续发送规划消息或用自然语言调整参数，复用原 task ID；已有流程不要求重新打开规划开关。未绑定流程的普通对话仍不生成任务页。

左侧工具下方展示“项目与对话”。点击条目同时恢复服务商会话和对应流程；上次选中的条目会恢复，隐藏 Agent 面板也保留其连接、对话和输入。每个服务商的会话独立，流程不能跨服务商或会话挂接。

只有明确点击“新建流程”后发送下一条消息，或明确表达“新建一个计算流程”等请求，才创建另一流程。原流程记录保留。会话索引指向当前活动流程，已有多个历史任务的旧会话按最近更新的任务迁移。

## 参数和文件

流程显示为相连的图文步骤卡，点击步骤展开菜单：

- 红点表示缺少必填参数，绿点表示参数齐全；同时提供文字说明。
- 数字、单位、选择、布尔、列表和文件字段直接编辑；嵌套参数展开为字段，默认不使用 JSON 审阅。
- 文件展示名称、路径和选择入口；实际模块输入记录仍可打开查看。
- 菜单填齐后保持展开，不中断输入。保存操作逐项合并，不因轮询或旧模型响应丢掉新手工修改。
- 旧字符串步骤和扁平参数仍可查看；未分组参数显示为独立参数卡。复杂自定义空对象保留高级编辑入口。

MCP present_task 保留 task_id、name、steps、parameters、missing_fields 五个顶层字段。steps 新增结构化对象，包含稳定的 id、title、description、tool 和 fields；字段 key 是 parameters 的路径，例如 md.temperature。禁止原型字段和重复字段。Python 服务与主进程分别校验。没有修改项目授权或科学引擎。

## 复核和执行

“复核”先保存手工值，在当前对话自动发起 AI 检查；直接更新同一流程并准备当前参数对应的实际模块草稿。参数发生变化、复核期间出现新手工输入、服务商请求失败，或缺少新草稿时，执行资格失效。

主进程要求复核版本、参数版本和实际草稿一致，才能执行。只读查询和重复返回旧草稿不能刷新其参数版本。点击“执行”后仍由 worker 检查真实输入与目标环境；集群分别显示输入契约验证和执行节点科学验证。绿色和 AI 复核均不等于科学验证通过。

提交响应不明确时保留原作业身份，提供状态核对，禁止自动重提。运行状态和结果来自 worker。实际任务不会因关闭桌面而结束。本代执行当前可执行模块，各依赖模块仍分别准备和审阅，不启动未经授权的整条科学流程。
