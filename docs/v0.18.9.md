## dev.10：运行知识与复核状态修复（内部包，未正式发布）

人工复核状态查询只读取当前会话所属任务的已保存 receipt 身份，不再要求任务先满足正式复核或执行条件。草稿尚无人工 receipt 时返回 not_run；旧运行的桌面索引尚为 queued，也不会阻断这个只读查询。原有文件读取、完整输入检查、复核确认、部署与执行门槛保持独立；不自动核对作业、不改 worker 状态，也不将 AI 复核当成人工确认。

新规划流程查询目标 API 前，公开主 skill 和工具说明要求用同一个任务 ID 保存明确引擎路线和诚实的待补项。空路线返回 route_not_bound 与同流程修正指导；不同的现有路线仍拒绝，不自动改写科学值、切作者环境、创建另一流程或扩大项目授权。

环境探测与目标 API 检查共用只读 Git 身份读取器。对于 Windows 管理、通过 WSL 访问的 linked worktree，验证有界控制文件、common 目录和回指关系后读取所选 worktree 的真实 HEAD 与 dirty 状态；不修复 .git、不切分支，也不拿另一个仓库的身份填入旧 receipt。原探测尚无 Git 身份时，严格 API 检查明确要求一次新的正常检查，旧模块能力记录不因此被伪造为失效或已通过。远程任务的固定 Python 包同时携带这个新增依赖。

补充修复环境摘要的路径误拦：MCP 仅把已知软件源码根、导入模块文件、sampling origin 三类路径投影为角色和原路径哈希。原始 worker receipt 不变，元数据视图不冒充原文；None 和未观察到的 Git 信息保留真实状态。未知对象正文不外传，原有私有路径、项目与服务商约束继续生效。DeepSeek 与兼容 API 的工具清单新增既有目标环境接口读取器，不能绕过当前任务、来源或环境约束；这不代表第三方真实账户调用已验证。

Git 固定子进程按原始字节并行排空 stdout/stderr，分别接受最多 262144/8192 字节，各最多多读一个溢出判断字节；有执行时限与仅针对自有进程的回收，不宣称整个解释器 RSS 上限。普通 native Git 保留其合法 worktree 解析方式，严格 metadata 回指检查适用于 Windows 到 WSL 的映射分支。测试直接入口移至文件末尾，与 discovery 覆盖同一组案例。
