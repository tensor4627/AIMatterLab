# v0.18.9 开发记录（未发布）

本轮按实际原生界面观察修复问题。完整控件验收、工作流使用次数统计、菜单层级调整和最终视觉审阅仍在进行；当前发布基线仍为 v0.18.8。已生成 `0.18.9-dev.1` 隔离内部测试包，不表示通过正式发布验收。

## 已确认的问题与修改范围

- 英文预览中的首页统计标签和说明绕过了翻译函数；账号入口、当前增强采样说明缺少精确词条。已修复这几个主要界面的漏译，保留科学软件名称、实际数值和未知状态。
- 原生界面中，同一会话的参数编辑与自然语言续填保留了流程身份；但重新加载渲染器会丢失未发送的消息。现已加入按服务商和会话保存、恢复输入草稿：只有发送获得确认且对应草稿未被继续编辑时才清空，旧请求不能覆盖新输入，恢复不触发自动发送。
- 新会话在本地登记完成前保留原草稿；会话恢复改名、删除及服务商来回切换按各自身份处理。存储写入失败不会阻断输入，迁移先保存目标，再清理源；删除时同时清理该草稿的迁移备份。
- 补充代码复核发现并修复了“切换会话并预填 CV 讨论内容”覆盖旧会话草稿的问题：预填在目标草稿选定后才应用，校验服务商和会话，旧请求不会在后续切换时再次覆盖文字。

本轮尚未批准基于按钮使用频率的菜单调整。科学输入、执行审批、SSH、凭据、引擎环境和真实作业不属于这些修复的修改范围。
