## dev.24：队列权限、顺序与逐队列环境（候选）

“连接计算资源”和设置继续共用同一套 SSH 编辑器。集群页增加二级“队列与环境”：每个目标保存队列、使用类型、支持引擎、环境、初始化脚本和单任务资源上限；高级环境字段折叠展示。目标和环境随连接版本保存，项目另行确认允许的目标、选择顺序及已知付费条件。Agent 可以提出设置和短例草稿，不能修改项目范围或自行提交。

只读探测同时观察 LSF 与 Slurm，区分当前选择与实际发现；不匹配时只能修改待保存草稿，不自动切换调度器。队列可见性不代表可用权限、所有权或价格。登录节点观察不等于计算节点环境或 GPU 验证。用户指定的本地 SSH 配置来源仍待确认，尚未真实连接、探测该集群或提交逐队列用例。

新任务可按项目批准的顺序选择兼容目标，或显式选择一个已批准目标。普通队列/账户文本不能绕过目标范围；显式目标失败不换另一个。准备、验证与提交都核对连接版本、项目策略和不可变目标/环境快照。策略变化只影响新准备与尚未提交的草稿审阅，不迁移、取消或重提排队、运行或状态未知的作业。已批准且费用条件明确的付费范围内不逐次重复授权；未知条件、变化或超限需要复核。当前只强制单任务资源上限，没有货币或累计费用计量。

部署页不再把旧单队列默认值误带入多队列选择；使用项目顺序时由 worker 解析实际队列与环境，并在提交预览中展示。已保存的手动草稿不在读取时自动改写，改用队列策略须显式选择；切换仍绑定原会话和任务。普通账号恢复仅建立模型/工具连接，不再隐式登记源码或发现计算环境；新作业服务的显式初次设置保留发现与登记能力。

兼容性：新队列字段采用显式启用方式，未启用的旧连接和旧作业保留原语义；空目标数组表示禁止新任务，不能回落旧模式。已存在项目队列策略时，连接退出该模式也不能绕过原策略。旧作业继续按原快照观察，不改 SSH、凭据、注册环境或运行记录。新版队列编辑需要匹配的作业服务；界面只提供按原来源更新的入口，不自动更新。计算资源 skill 记录了最少询问、队列确认、逐目标测试和复用运行时登记的规则，不含私人连接信息。
