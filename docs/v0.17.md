# v0.17.0 · 可靠流程编写与全流程回归

2026-10-20 本地交付。A 真实操作、B 工程改进、C 独立审查的三轮迭代均正式通过；随后完成 ABC 联合界面改进和最终追加验收。首次失败、退回与返修记录保留，未用模拟结果替代科学运行。

本代重点：

- 会话自动绑定仅供编写输入的草稿项目，原会话持续更新同一流程。Agent 能读取真实源码契约、用 ASE 检查结构与拓扑、保存 CV/Bias/driver，再按文件 SHA 原位修改；不再因项目列表为空而只能把源码塞进参数框。
- 引擎契约覆盖当前 15 条已实现路线；图输出形状、真实输入、参数版本、准备快照和提交身份相互核对。手工修改退回 AI 复核，历史成功作业不冒充当前参数已验证；人类确认后才执行。
- 草稿与计算授权分开。新增明确的项目授权表单；当前保存输入可只读预览文本、大小与 SHA，二进制仅显示元信息，未来文件显示实际缺失状态。不会自动授权父目录或升级草稿权限。
- 修复会话切换、迟到复核/准备回包和旧模型事件串页。普通聊天与显式流程规划分开，否定或解释“新建流程”不创建任务；科学 worker 断开时仍可普通聊天。模型成功标记绑定本次选定的服务商、模型、会话与 turn。
- 默认列出 Studio 会话，外部会话由人类显式导入。优化大字号侧栏、阶段栏、配置区滚动和中英文可达性；设置保留字体、字号、语言、主题与 Agent 两种布局。
- One-prompt 增加现有环境复用验收：独立控制端/worker 目录、实际探测、三个真实短例、严格零工具模型回复与生成启动脚本复开。开发闭环沉淀为独立的开发 skill，不混入产品科学技能。
