# v0.18.8 · 会话导航、可调工作区与紧凑流程

日期：2026-10-29。本代围绕对话、计算流程和任务状态收拢一级导航，减少反复关闭页面和逐项检查参数的负担。

## 用户可见变化

- 左侧窄栏保留会话、技能库、任务总览、设置四个主入口。会话区包括账号与 API、新对话、新建计算任务、搜索、置顶、项目和无项目对话。「新建计算任务」默认打开规划模式；「新对话」默认普通聊天。
- 支持创建会话项目，在会话菜单中置顶、取消置顶、移动项目或移回无项目。项目用于整理对话；每个流程原有的计算工作区、算力及授权继续独立保存。归类或置顶不创建计算项目、不扩大执行权限、不改变流程标识或对话时间。
- 会话列表和对话/内容之间均可拖动。对话面板不再限制在原来的窄宽度，左右两种布局都可让对话占主要空间；窗口不足以容纳双面板时切换为单面板。分隔线支持键盘方向键、Home/End 和双击，宽度及布局持久保存。
- 内容区采用当前页面预览，访问技能、工具、任务等页面会替换当前页，不再累积一排标签。切换会话自动打开它自己的计算流程；原会话的流程、部署数据和未发送输入仍然保留。未保存的代码编辑仍有离开提示。
- 技能库内提供计算链条和软件功能入口。任务总览默认跨计算项目，展示规划中流程以及本地/集群运行、排队、待核对状态，并可返回所属会话。状态来自已有作业记录；未读取的来源不显示为零，断线保留待核对标记和读取时间，不自动重交任务。
- 流程页面最多展示四个关键参数摘要。模块默认折叠，摘要最多显示三个值；展开后先展示最多四项基础参数，其余基础项及高级项分别折叠。红色缺项提示可展开对应层级并定位具体输入。参数值、软件原生字段及执行门槛没有被删除或替代。
- 自定义 API 保留手填 Base URL、模型 ID，不依赖 `/models`。推理设置可选择不发送额外参数，或填写服务商支持的 `reasoning_effort` 值。支持厂商自定义 token，不假定它只接受 low/medium/high；这仍是 OpenAI 兼容 Chat Completions/SSE/tool_calls 接口，不代表支持所有厂商原生协议。
- 修改同一 API 地址的模型/推理设置时，密钥留空保留已存凭据；更换地址不会把旧密钥自动交给新地址。旧对话的服务地址绑定继续生效。
- 修复实际便携版检查发现的旧问题：自定义 API 登录将 pyGAS 共享范围重复写入另一共享字典，导致之后保存布局设置失败。启动时移除该冗余字段，以原有独立 `pygasSkillProviders` 为准，不合并或新增授权。
