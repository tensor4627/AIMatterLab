# v0.12.0 · 第二轮：真实提交、输入复核与结果回收

本轮是源码里程碑，第三轮统一检查便携包；未为此版本建立发布标签。

- 集群运行页接入终态结果回收与文本预览。回收按原 Run 目录、授权范围和文件哈希登记资产；重复回收不重新计算。切换任务清除旧结果，异步响应不能串入另一任务。
