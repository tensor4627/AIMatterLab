# AIMatterLab 0.2.12

## 修复范围

- 同一 SSH 作业服务更新观测时间、修订号或工具清单后，已有会话可继续检查服务。前台接入和后台重核均核对服务身份。目标替换、维护或撤销发生后，较早返回的检查不能覆盖新登记。
- 服务检查保留首次失败的通道、时间、步骤和安全原因。项目检查标明所查项目，区分草稿工作区、项目不存在、缺少匹配授权和未能核验。查询失败时提供已知的步骤与 HTTP 状态。有独立授权的命令和队列检查仍可使用，提交与取消继续核对原项目、目标和作业。
- SSH 配置草稿会携带本轮需要的指南。环境、工具配置和安装检查入口也可选择相应指南，草稿和排队消息中的公开指南随原会话恢复。

相关报告见 [#1](https://github.com/tensor4627/AIMatterLab/issues/1)、[#2](https://github.com/tensor4627/AIMatterLab/issues/2)、[#3](https://github.com/tensor4627/AIMatterLab/issues/3) 和 [#4](https://github.com/tensor4627/AIMatterLab/issues/4)。

## 内置指导

计算工作流的作业服务配置与连接恢复参考已更新。Agent 可按检查结果说明项目、失败步骤和已知的 HTTP 状态，再根据当前会话持有的能力选择后续操作。核对了资源选取、显式终端交接、原连接重读、作业服务接入、配置草稿和排队消息的桌面入口及工具定义。

其余技能及引用按 0.2.11 已审阅的内容与本次源码差异核对，涵盖主 Agent、工作流编写与规划、工具发现与接入、安装检查、数据、分子动力学、NEB、CV/Bias、OPES 和训练。核对范围包括功能映射、运行指令、普通会话与绑定流程的逐轮提示，以及恢复会话后的指南选择。
