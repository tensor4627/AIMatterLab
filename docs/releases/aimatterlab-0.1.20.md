# AIMatterLab 0.1.20

2026-11-19 · Windows x64 · [更新日志](../../CHANGELOG.md)

## 资源与会话

在统一的计算资源界面核对程序托管的连接、各资源的作业服务和分配给会话的通道。SSH 登录和作业服务使用权各自核实。会话按用户指示取得自己的通道，普通聊天可以查队列、配环境。需要项目授权的操作会说明所缺的权限。确认来源和目标后，已获授权的聊天也可以准备、验证、提交和追踪独立作业。任务规划面板适合需要组织多步计算和审阅参数的工作。

内置系统提示、逐轮指引和队列 skill 使用同一托管流程。更新后的打包检查将实际读取成品中的科学 skill 并核对来源，保留个人工作区的自定义笔记。[开发规则](../development/README.md)

## 旧版故障定位

在 0.1.18 的实际 DeepSeek 工具记录中，SSH 已发布，私有服务就绪。资源清单里的 `verification_pending` 表示尚未核对 worker 的项目权限。用户提出查询空闲队列后，旧的指令解析未识别该请求；即使按名字确认，申请也在分配终端前被拒绝。后续服务查询又要求已有 workflow。两步都没有向 SSH 发起新的认证。

当次实际读取的个人 skill 没有交接指令。内置 `compute.queue` 返回了旧的「交给 Agent」流程。0.1.18 安装目录、NSIS 与便携 ZIP 中的这份指导和当时的源文件逐字节一致。现已同步更新工具说明、系统提示、逐轮指导、内置 skill、旧对话恢复时的提示和界面生成的委托草稿。

## 使用

- 在左栏「计算资源」查看 SSH 认证主连接、人工终端、私有作业服务及具体会话的通道。可打开原终端、查看对应会话、释放指定通道，或核对某个平台的服务与授权。断开主连接会显示其影响范围。
- 在普通聊天中直接说要查哪个集群的队列。多个候选时选择目标，已发布的 SSH 可以给该对话分配独立终端。任务规划用于组织和审阅多步计算。需要提交独立作业时，说明目标并明确要求提交，软件在相应权限内记录调度回执。
- Codex CLI 版本与内置基线不同时会检查实际能力，兼容时显示一次黄色警告。提示使用主题原色，错误使用红色，图标和文字也说明严重程度。
