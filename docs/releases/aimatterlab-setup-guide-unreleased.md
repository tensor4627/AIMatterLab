# AIMatterLab 首次启动与新手引导

2026-11-18 · Windows x64 · 0.1.9 后的源码改动，待发布。[更新日志](../../CHANGELOG.md)

新配置首次启动时打开四步引导。关闭桌面会保留当前步骤。完成或跳过后，用户可在标题栏重开引导。已有配置升级后会直接回到工作台。

| 页面 | 用户可以设置或体验的内容 |
| --- | --- |
| 欢迎 | 中文或英文、浅色或深色外观，查看并打开本机工作区或指定的配置目录。初始语言取自系统。 |
| 助手 | 选择 Codex、Kimi、Qwen、DeepSeek 或自定义 API。可以进入对应账号设置，或在普通对话中草拟一条测试消息。 |
| 算力 | 选择本机 WSL、远程 SSH 或稍后连接。WSL 复用发行版连接指引。SSH 支持选择已保存的连接、新建连接或从已有 SSH 配置导入，用户在原有终端完成认证。 |
| 开始 | 旋转铜晶胞，按导入结构、描述目标、核对流程、预览部署、查看结果五步浏览 MD 示例。可把示例目标带入可编辑的任务规划对话，进入工作页登记环境、获取科学工具，或准备安装短例。 |

安装短例沿用安装清单中的 `worker`、`reference-md` 和 `pydyn-md`。向导将选择带入可编辑草稿，由用户决定是否发送。账号配置、模型回复、SSH 认证和作业服务分别显示观察到的状态。[软件规格](../software-specification.md) · [安装与就绪检查 skill](../../agent/builtin-skills/studio-install-readiness/SKILL.md)

## 工作页教学气泡与助手首轮索引

引导打开正式工作页后，气泡显示本课目标、下一步操作和返回入口。整个气泡支持点击和键盘操作。返回时保留示例步骤、已展开的选项及所选安装短例。工作台使用独立的布局空间显示气泡，用户可以同时操作正式页面。

五种服务商从同一份运行时 `AGENTS.md` 获取技能索引。普通新对话按用户消息查询项目、个人或科学技能，读取所需条目。用户明确选中的技能和已绑定流程沿用原来的作用域。安装版也读取当前工作区的补充索引。[本地技能工作区](../project-skill-workspace.md)
