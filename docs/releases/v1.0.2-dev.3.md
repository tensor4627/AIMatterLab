## 保留的首轮失败

- `portable-build-first.log`：首轮额外设置 `npmRebuild=false`，使 builder 在调用项目 `beforeBuild` 前返回，未声明依赖已外部装配，随后触发 pnpm SQLite 依赖收集错误。移除该参数后使用既有公开 hook；实际 hook 验证资源并返回 false，正常跳过依赖安装/重建，成功生成便携包。没有修改依赖库、外部 store 或系统配置。
- `verification-1794310550231.json` 和 `verification-1794310568651.json`：静态核验脚本最初未适配 Windows ASAR 分隔符、额外可信 elevate 文件、Windows 数值版本及 NSIS 启动器架构，不能据此认定包有缺陷。修正核验适配后，采用内嵌 7z 的 CRC/边界与实际字节一致性验证，最终通过。受限宿主无法加载 Authenticode PowerShell 模块，因此根据 PE 证书表确认无签名，未将密码学签名验证记为 passed。
