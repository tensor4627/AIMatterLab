# AIMatterLab 0.2.13 发布与验证

## 会话权限、部署与更新公告

用户配置提供计算连接和 Windows 软件目录的基础权限。Agent 选项的「会话审批」显示当前会话额外批准的操作，允许撤销在本会话内有效的 Windows 读取授权。新部署从流程所属会话直接选择资源，worker 为该部署生成内部授权记录。已有作业按原记录核对。

应用内更新完成后，首次打开新版本时显示本版公告。公告随软件打包，可从版本按钮打开「软件更新」并展开「当前版本更新公告」。
