# 集群工作区外输入复制验证

2026-11-17。本记录对应 0.1.8 之后的源码修复。

原流程已在所选计算资源上建立草稿，传给 Agent 的编写指令却要求先选择具名工作区。终端列出的源文件也没有对应的项目副本，工作流读取器因此拒绝直接打开。

现在，Agent 可以在当前对话中调用 `copy_project_inputs`，把该资源上指定的外部普通文件复制到当前草稿或已选工作区。一次复制保留文件名和相对目录。作业服务先完成整组复制，再发布到项目输入目录，按文件回读并记录 SHA256。相同输入可复用已核对的副本。对已编辑的副本再次请求同一组时，服务保留编辑并报告差异。工作流读取和编辑均使用副本路径，项目的写入、模型共享和执行权限沿用现有规则。

新桌面配合支持此接口的作业服务使用。旧服务收到复制请求时会提示更新。用户在原 SSH 连接明确更新服务后，桌面核对主机、账号、项目和输入目录，再更新当前未部署草稿的服务版本绑定。已准备或提交的作业保留各自的来源记录。
