## 本地 SSH 恢复与 Codex 接入复验

原桌面在同一已认证 SSH 上读到私有作业服务在线。通过托管面板重试后，服务登记变为已登记，终端显示作业服务可用。随后在「用于当前流程」复现 `ssh_service_channel_in_use`。终端把它显示为 SSH 连接需要核对，详情把失败动作显示为连接操作。现场缺少首次传输中断时的网络记录。

修复版使用原连接上的服务身份和实时健康回执。首次设置还会比对实际准备的随包文件摘要。恢复流程可撤销一个尚未绑定服务、已被其他活动通道替代的启动请求。终端进程在记录撤销时核对原请求与替代请求。流程面板保留显式重试入口。Codex 对话恢复已启用的本机订阅后，账号读取使用持有该订阅的对话进程。
