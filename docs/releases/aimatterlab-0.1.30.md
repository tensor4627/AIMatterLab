# AIMatterLab 0.1.30

2026-11-23 · Windows x64

## 会话交互

- 回复进行中，默认按 Enter 把下一条消息加入原会话的队列。按 Ctrl/Cmd+Enter 可引导支持该能力的服务商。Kimi 支持排队。在 Agent 选项中可以对调两个快捷键，Shift+Enter 换行。
- 切换会话后，原会话仍会继续发送排队消息。可以编辑、调整顺序或移除排队项。手动停止保留已经显示的回答，随后可在同一会话续发。
- 在输入框用回形针、拖放或粘贴添加文件和图片。可以预览、只发附件，或带附件排队。文本、日志和计算输入保留文字，PDF、DOCX、XLSX 和 PPTX 在本机提取内容。扫描 PDF 可先做 OCR 或作为图片发送。PNG、JPEG、WebP 和 GIF 需要支持视觉输入的模型。
- 可从侧栏直达待回答、待审批或有新结果的会话。在聊天中可引用已授权输入、日志、文本产物的行段与参数差异，预览选取时的内容。
- 长会话支持分页、搜索、命中定位、引用、书签和可恢复归档。Codex 可从指定的已结束回合分支，其他服务商可在预览摘录后开始新讨论。
- 切换会话或服务商后，旧连接的失败回执仍归原连接。提示安装 CLI 的弹窗只会在发起该连接的前台会话出现。

操作细节、附件大小限制和开发阶段的对照结果见[会话工作区验收](aimatterlab-chat-workspace-unreleased.md)与[跟进和中断验收](aimatterlab-chat-turn-followups-unreleased.md)。

## 内置指导复核
