# AIMatterLab 0.1.22

2026-11-19 · Windows x64 · [更新日志](../../CHANGELOG.md)

0.1.21 的真实会话中，用户先要求探测集群队列，随后在聊天里点名。旧实现只有在识别到特定操作动词后才记录已列出的候选，确认消息又依赖上一轮的候选。因此桌面收到正确的目标 ID 后仍返回未派发。

用户现在可以直接在聊天中点名。多候选时，助手可以列出名称和标识，用户用文字答复即可；当助手传错 ID，桌面会返回用户原本选定的资源及申请参数。授权的会话可申请该资源的服务或独立终端。记住的选择只适用于相同服务商、会话、项目与工作流范围，重新申请仍核对现有资源指纹和当前权限。[产品规范](../software-specification.md#弱校验与-agent-自主性)
