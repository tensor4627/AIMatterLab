# AIMatterLab 0.1.19

2026-11-19 · Windows x64 · [更新日志](../../CHANGELOG.md)

应用内更新请求现在使用 AIMatterLab 的客户端标识。旧版发出的 Chromium 浏览器请求在南大站点收到 HTTP 307，随后进入网页安全验证。更新界面曾把该网页提示为仓库权限问题。

更新面板显示各发布源的 HTTP 状态，区分网页验证、认证失败和清单不可用。成功读取签名清单后，如果已安装版本更高，面板会显示发布源的版本号。
