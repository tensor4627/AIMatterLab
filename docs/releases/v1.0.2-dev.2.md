## 保留的失败与复核

- 独立后端审查首轮拒绝了启动协议 schema 降级绕过：现由 scheduler 额外固定已提交 claim，删除、替换 schema 或剥离 metadata 均不能变成旧协议执行。
- 独立后端审查发现 ACP 取消后迟到 ENOENT 可成为未处理错误：现保留 settle-safe 错误监听至 close，并用实际不存在的可执行路径复验。
- 独立前端审查发现保存后立即关闭会使 renderer 与持久化基线分离：现对父级关闭和所有设置退出入口加锁，并以实际 App + SettingsPage 集成复验。
- 首次浏览器冷启动用例缺少 `compute.profiles.read` 适配器，导致 fixture 连接失败；补全该既有接口后重跑通过，保留首失败，不归为产品缺陷。
- 标准目录包构建的 pnpm 收集失败、原生预检及 WSL 受阻均保留原输出，没有记为通过。
- 续查确认当前 16 份后端、协议及测试源码摘要与已通过的独立审查记录一致；前端及 worker 两路复核未发现新缺陷，沿用本代原始定向工程证据，没有重新计数或启动科学任务。文档链接、7 份契约及 diff 检查再次通过。打包续查保留于同一忽略目录的 `fixes/continuation/`；未修改已安装依赖元数据、外部 pnpm store 或用户设置。
