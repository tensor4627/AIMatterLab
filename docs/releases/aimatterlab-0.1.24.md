# AIMatterLab 0.1.24

2026-11-20 · Windows x64 · [更新日志](../../CHANGELOG.md)

DeepSeek 遇到需要用户决定的单选问题时，在聊天输入区显示候选项，也接受自填答案。收到托管计算资源的候选回执时，桌面会据实际候选生成选项，并在提交时核对会话和目标身份。已有明确目标的请求继续使用原有入口。

此前，Agent 栏使用前台 worker 的状态描述普通聊天的科学工具。已托管的 SSH 作业服务通过每个对话自己的工具通道提供队列观测，因此工作台可能在探测成功的同一会话中提示连接计算资源。本版分别核对该对话的托管工具目录和原流程作业服务。集群在线状态仍由计算资源面板显示。

## 内置指导
