# AIMatterLab 0.1.28 本地测试版

2026-11-22 · Windows x64 · [更新日志](../../CHANGELOG.md)

安装包为 `AIMatterLab-0.1.28-win-x64-setup.exe`，便携包为 `AIMatterLab-0.1.28-win-x64.zip`。两份包位于 `release/v0.1.28/`。要沿用已有连接和项目配置，退出旧版后选择原工作区安装。便携包可在源码仓库之外解压到独立目录试用。

## 复测手选节点与交接

1. 在计算资源里找到原 SSH 配置，使用 Windows OpenSSH，选择「交互式登录」或「重新登录」。
2. 在私有终端输入密码和验证码，按站点菜单选登录节点，等到节点的命令提示符，再点击「登录完成，交由 AIMatterLab 管理」。
3. 确认面板显示 SSH 已连接。首次交接时核对远端账号、节点和工作区路径，再点「确认并交接」。如果目录检查失败，应在「远端工作区需要核对」中看到原因，可用原连接重新核对。
4. 交接后可在普通对话中请 Agent 只读查看目标集群的队列。核对结果是否来自已选节点。需要回报异常时，可记录错误码和所在步骤。

## 内置指导

本版在计算技能、队列发现、工作区和作业服务参考、科学功能图、运行时指令、逐轮资源提示及 DeepSeek 策略中同步了命令、终端和作业服务的入口。工作区确认使用原登录中观测到的节点和账号，未知操作沿用原请求 ID 或调度器回执。[SSH 流程](../ssh-cluster-management.md) · [工具及授权](../../backend/main/compute/managed-compute-resources.mjs) · [逐轮提示](../../agent/sessions/resource-routing.mjs)

逐份核对了 11 个内置技能及其引用，检查产品名、工具与引擎登记、控件用语和源码引用。安装、总控、资产与数据、MD、CV 与偏置、训练、NEB、OPES、流程编写和流程图指导与 0.1.27 一致，沿用同一组引擎契约和证据来源。本版的启动提示仍在 2,500 字节内。技能读取的范围检查覆盖已登记且显式共享的上游技能夹具。
