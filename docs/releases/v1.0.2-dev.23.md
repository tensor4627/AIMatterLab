修改仅限此链路：

- 连接登记、OpenSSH 参数构造与本地认证助手一致支持 `login/asset-host/asset-account`，完整用户名作为单个 `-l` 参数传递，不拆解为 shell 命令，不猜测资产或自动修改现有连接。缺失／多余段、控制字符与命令注入仍被拒绝。
- 服务通道打开期间持续报告 connecting，避免尚未执行 bootstrap 的 idle 状态被前端轮询误认为连接丢失。

- 服务只在真实健康、工具清单和上下文核验后才授予 Agent。用户提供密码／验证码的交互输入保持私有。
