# AIMatterLab 0.1.18

2026-11-19 · Windows x64 · [更新日志](../../CHANGELOG.md)

科研助手连接已有对话时，现在先用该对话的身份绑定工具通道，再启动 DeepSeek Harness。以前桌面会给刚启动的 Harness 一个空白对话的凭据。工具服务核对已有对话时返回 HTTP 403，Harness 的工具插件启动失败，界面在 30 秒后才报告隔离检查超时。

账号页使用独立的连接测试会话，科研助手则需要取得当前对话的工具清单。现在工具插件启动失败时会立即报告失败阶段和工具服务的 HTTP 状态，桌面仍须收到通过隔离检查的回执才会显示已连接。
