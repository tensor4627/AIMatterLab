## 使用上的变化

- 一个会话持续管理一个计算流程。Agent 和用户可在原页面更新参数及实际文件；缺项红点可定位，复核和执行保持独立。普通对话保留聊天行为。
- 基础科学参数放在前面，源码依据、默认表达式、实现细节和完整文件身份折叠展示。UI、Monaco、终端和 ECharts 使用可调整的字号下限。
- 参数建议来自当前保存的源码和输入契约。用户可明确补齐空白值，保留已有填写；不会把 Bias 温度推成初始化温度。实际模型界面链能读取本地输入、补齐技术路径并在同会话同步修改。
- 技能库统一管理功能、阶段、来源、依赖和提供方共享范围。当前生产路由审计读取了 36 个功能、20 个指南和 92 个有界附件。安装或修复指南仅在明确选择对应阶段时载入；普通计算复用真实探测后的精简环境信息。
- pyGAS 使用注册源码中的 CV/Bias/Switch/Neighbor 类名、构造参数、类型、默认表达式和输出维度。PLUMED 示例需核对公式、单位、原子编号、PBC 和归约；增强采样继续遵循 pyGAS 工作流。
- 自定义 CV 先讨论并确认公式，使用独立私有库、确定性 primitive 和有界数值检查。按精确版本授权提供方读取，撤销会再次校验；参数改变会使复核与数值绑定失效，历史记录保留。
- 同流程支持真实产物采用、原生消费输入、目标确认及现有作业状态核对。准备与执行前继续验证参数版本、快照、运行时身份和资源范围；未知作业只核对。
- Agent 回复支持安全的加粗、代码和基础列表。恢复会话保留当前模型支持的用户 Effort 选择；真实测试中服务端仍回报 high，界面正确保持 low。
- 修复普通 GPU-Sampling 流程在没有人工复核凭据时保存部署的 SQLite 空 ID 错误。既有 AI/人工复核权限不变；原失败流程保留参数和已构建产物，直接恢复部署并执行。
- Codex 桥接固定到实测 CLI 0.163.0-alpha.11.2，生成对应官方类型并验证协议边界，未知版本继续明确拒绝。

## 科学与兼容边界

本代为 1.0 前开发预览，没有修改科学引擎仓库。界面整理可调整开发数据结构；SSH、凭据、环境、授权和真实运行状态继续保护。1.0 后按版本迁移及兼容政策处理。

NEB 界面短例到达 32 步上限，最终 fmax 约 0.7683，高于 0.01 阈值，优化未收敛。WT 界面样例的初始历史为空，初态导数响应为零，只能记录该检查范围；不能据此宣称非零偏置导数、物理应变 virial 或长时间采样验证。短训练、有限输出和正常退出不证明势质量、DFT 精度、自由能或生产收敛。不同路线、历史和导数契约不互相替代。

当前已有登录的 Codex 环境与真实调用通过；新账户、全新机器端到端安装、其他服务商本轮实际推理、新 SSH 提交和生产规模计算为 not_run。缺少 Materials Project key 的真实查询 blocked。TorchNEP、NEPMaker、ActiveMiao、外部 DFT 及 PyDyn NEB 等未实现的 Studio 执行适配器继续明确标记。未经审阅的私有混合、OPES、AOTI 部署路线 blocked；显式 AOTI 不自动换后端。参数恢复后的私有 CV 当前定义仍需重新数值验证。
