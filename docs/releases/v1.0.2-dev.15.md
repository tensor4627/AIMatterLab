# 1.0.2-dev.15：同次认证的独立计算资源通道

本代按更新后的[计算资源规范](../software-specification.md#计算资源)改造连接层。dev.14 仅修复 Agent 识别、发现权限及只读探针，仍占用共享终端，不属于新版规范完成包。

基础 SSH 连接使用独立认证 master；人工完成主机信任、密码及 MFA 后，核对真实进程、私有 socket、远端回执，再分别打开普通 shell 和私有服务通道。所有从属通道依赖该 master，缺失时固定失败，不再登录、不更换主机。普通 shell 保留历史、输出和人与 Agent 输入权交接，服务有独立的当前对话调用权。关闭 shell 不关闭服务；停止服务不停止 shell、master、远端 worker 或作业；明确结束整个连接才撤销其上的临时通道与授权。

服务按 connectionId 保存。切换资源只撤本地代理和旧授权，保留后台通道；再次明确选择时核对原 serviceId/attempt，再接回代理，不重复安装或启动 worker。单能力未知不掩盖另一个独立核验能力，也不自动重放。调度配置保存绑定确切 connectionId、attemptId 和选中来源，后台 A 不能写入 B。

连接配置新增不可变真实版本快照及校验摘要；既有数据只回填当前实际保存的版本，不虚构丢失历史。资源引用 schema 2 绑定 profile/version/connectionId，shell 开关不改变该身份；显式选择新连接时留存旧 schema 1 引用和迁移记录。历史记录不提供认证或 Agent 权限。环境配方通过 broker 准备锁、精确修订和异步提交回执更新；保存不等同活跃连接已采用，未知提交不自动再发。服务解释器及派生环境指引保持私有配置边界。
