## 行为与兼容

- Windows PATH/PATHEXT 支持大小写、带引号的目录以及常见 npm/pnpm 包装入口；解析真实入口后直接启动，不执行 shell 包装器。有效手动配置保留，只迁移失效的历史包内默认路径。
- 下载固定官方 npm 包及依赖，验证完整性，受限解包，隔离 ACP 初始化后原子发布；不运行 postinstall。显示实际下载字节/包数及校验、安装、接口检查阶段，支持取消与失败恢复。CLI 就绪不等于账户登录、模型访问或科学结果。
- 构建、开发和源码启动准备物理 PTY，避免依赖上层工作区的 pnpm 安装；打包复用并核对本机锁定的 Electron 44.5.1。
- 连接资源扫描、哈希与复制移出主线程，合并重复准备和健康观察，保留全部内容/身份核验。WSL 复用同次接入的观察，保留 relay 独立验证；只读请求超时贯通 SSH 传输。
- 独立连接层协商紧凑文件包与响应压缩，保留 96 字节响应分片、解压限额、确切取消、私有终端屏障和请求不重放。8 KiB 上传候选收益不足，默认仍为 2 KiB。
- 页面按需加载，列表各项返回即显示；常规轮询减少静态项目/环境读取，继续观察作业。活动 Agent 和终端保持挂载。
- 连接、账户、终端、文件、环境、导入、部署、运行与保存立即反馈操作名；等待超过约 150 毫秒显示动画，多秒操作显示已用时间，有真实总量才显示确定进度。防止重复点击和迟到响应覆盖新选择。300px 终端面板至少保留 64px 终端空间，长提示滚动而不挤掉终端。
- 安装技能、INSTALL_AGENT.md 和单 prompt 安装说明已同步补充 CLI 流程；`reuse-existing` 保持跳过下载，缺失时记录 blocked，用户准备好后再复核。

**作业服务与科学引擎保持基线字节不变。** 138 个 worker 文件的指纹仍为 `62034ec6cfc1428aaa4d`。队列并行探测候选已撤回：它会改变 worker 指纹，触发已有服务升级并使旧 SSH 流程绑定失配。该项留待具备明确兼容迁移时实施，本轮保留原队列探测并提供等待反馈。

真实隔离旧服务检查通过：先用原 dev.9 连接层建立服务并保存项目/输入 sentinel 和 SSH 流程绑定，再接入优化连接层。PID/启动时间、runtime/root、数据库状态及原绑定一致，`restoreTaskWorker` 返回 current；只传输 10 个连接层分片，无 worker 重传或控制器升级。
