# v0.13.0 · 第三轮：可迁移 skill 与服务商上下文

2026-10-17。本轮交付可检查的实验版便携包，保留 Codex、Kimi、Qwen、DeepSeek API。真实集群全链路验收仍在原作业上继续；下表将软件通过与尚未执行的计算分开。

## 本代改进

- 通用 `studio-compute-workflow` skill 包含科学流程、已有环境发现、LSF/Slurm、单任务 MetaD、实际 bias gate 和同作业回收规则。开发从 `agents/skills` 发现，便携包从物理 `resources/studio-skills` 发现。
- 本机特殊配置由显式 profile 生成到 `.studio/local-skills/<id>`：检查精确 Git 根、真实 ignore/未跟踪状态、链接与越界、原子创建、不覆盖旧版本；不复制用户级 skill，不保存 SSH 端点或凭据，不安装引擎。已实际为隔离验收登记生成私有 overlay；没有改动正常用户连接或授权。
- DeepSeek、Kimi、Qwen 的所选 Studio skill 附带受限 references；本机 overlay 还带 schema/provenance 核对后的私有元数据。公共父入口固定映射到已登记 bundled 根，文件身份、单文件/总量/数量与版本均受检查。元数据明确为数据，`local_skill_refs` 全文不读取，renderer 没有文件访问接口。
- `cluster-reconcile.mjs` 复用已有 Run 和调度 ID，只允许状态、终态回收和结果预览。传输收据、源 SHA、资产身份和 UTF-8 预览大小/hash 分开核对；断线与超时保持 unknown，不自动重提。源码和便携包都提供独立物理工具，不要求集群安装 Agent CLI。
- 空会话首 turn 明确被服务拒绝时仍可在同进程恢复；成功/原生 started 后转原生历史，传输不确定时废弃空历史缓存，待确认请求不允许并发恢复。
- One-prompt 安装入口补齐 DeepSeek、先科学后部署、复用预装环境、真实计算节点验证和私有 overlay 的操作说明。

DeepSeek：Agent → 服务商 **DeepSeek API** → **登录 / 账户** → 保存 API Key 并连接 → 从实际账户目录选择模型。已知支持的模型默认关闭思考，可切换 effort；没有测量或保证相对 Codex 的 TPS。密钥继续由主进程系统加密保存。
