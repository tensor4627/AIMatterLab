# AIMatterLab 0.2.7

本版更新运行时指令和工具知识。Agent 可以在普通聊天中找产品入口、科学方法、源码和随版本收录的工具。工具定义、目标环境配置、测试和激活分别保留证据。重型工作流与科学指导移到按需参考。

## 验证范围

改动以 [运行时 AGENTS.md](../../agent/context/AGENTS.md) 为入口。具体按钮、源码与科学方法按功能读取。计算资源、流程编写、路线图与 CV 的长说明移入专用参考，四项入口为 2,352–3,773 字节。启动指令为 4,501 字节，最长的内置入口为 4,545 字节。

工具目录、聊天查询和自动路由采用同一份发行清单。HotHam 显示为发行目录已收录上游来源和交付指南，原生计算后端待接入。选定登记的便携包后，受支持的托管 SSH 配置保留包版本、提交、定义摘要和参考用例，并在真实目标上核对入口文件和测试产物。现有桌面通用配置器仍有自己的适用范围。个人、项目、会话和资源技能继续使用各自的存储范围。详见[软件规范](../software-specification.md)和[技能库](../project-skill-workspace.md)。
