# 1.0.2-dev.12：模型 Harness 路由与分层提示词

同代独立 SSH 流程修改与验证见 [SSH 服务登记与会话交接补充](v1.0.2-dev.12-ssh-service.md)。该补充不将源码测试视为便携包或真实集群验收。

DeepSeek API 使用官方 DeepSeek Harness；自定义 OpenAI 兼容 API 使用官方 Codex app-server。Codex 登录、Kimi Code 和 Qwen Code 保持各自的官方 Harness。此代不修改科学引擎、已注册环境、SSH 连接、项目授权或真实作业。

## 功能与兼容

| 接入 | Harness 与边界 |
| --- | --- |
| Codex 登录 | 原官方 Codex app-server 与登录配置 |
| DeepSeek API | 官方 DSH 的 SDK JSONL 接口，独立 Studio DSH_HOME；实际工具清单仅允许当前 Studio 授权工具，禁止原生 shell、文件编辑、子代理和提交计算 |
| 自定义 API | 独立 Codex app-server 与 CODEX_HOME，固定所选模型；本机协议适配层将 Responses 转为既有 Chat Completions API，每个模型请求仅转换一次，循环和工具调度由 Codex 执行 |
| Kimi / Qwen | 原官方 CLI 通过 ACP 接入；ACP 是协议，不替换其 Harness |

- 从 [DeepSeek 官方项目](https://github.com/deepseek-ai/deepseek-harness) 对应的 npm 发布获取 DSH、SDK minimal 与 MCP 组件，固定 `0.2.2-rc.1`，依赖记录在 `pnpm-lock.yaml`。安装期间不运行依赖安装脚本，不读取或修改用户原有 DSH 配置。接口参照 [SDK](https://github.com/deepseek-ai/deepseek-harness/blob/master/packages/sdk/README.md) 和 [CLI](https://github.com/deepseek-ai/deepseek-harness/blob/master/apps/cli/README.md) 官方说明。
- 官方组件进入独立可迁移资源目录，校验文件哈希、版本、平台和依赖解析，保留冲突依赖的独立版本。不依赖另一台机器的绝对安装路径。当前完整发布依赖闭包为 658 个包位置、65,587 文件、708,158,343 字节；不把完整官方发行版的体积描述为仅 SDK 代码体积。
- 自定义 API 上游密钥仅由主进程中的协议适配层使用；子进程只接收随机本机连接令牌与当前工具令牌。不继承用户 Codex 登录或其他服务商密钥，不发生后端回退。
- 旧对话采用版本化、延迟迁移，保持对话 ID、工作流绑定和原始历史。恢复不发起推理；下一条明确用户消息可携带标记为历史数据的旧文本，不重放旧工具调用、草稿或未知作业。自定义端点改变后禁止将旧记录发送到新地址。
- 所有 Harness 使用相同 Studio 核心角色、当前交互模式、工具范围和人工 Execute 边界。常驻提示词保留共同规则；先披露技能目录与任务入口，支持资料通过精确文档 ID 按需读取。主协调技能的详细作者流程移入支持文档。手动选择的工具技能也默认只加载入口，后续通过绑定当前对话、回合和确切登记版本的不透明文档 ID 读取；不接受调用方路径或包版本替换。明确选择的 setup 功能保留本回合的精确阅读许可，下一轮、上下文／租约变化或派发失败即失效；普通计算不加载安装资料。
