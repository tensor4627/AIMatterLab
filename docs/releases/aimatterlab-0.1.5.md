# AIMatterLab 0.1.5 合并与验证记录

2026-11-17 · 本地源码合并 · [更新日志](../../CHANGELOG.md)

在本地 main 的 0.1.4 与 HotHam 合并提交 `b8404496196c595dfae4035b6337bbe0a3ded98d` 上合入 [PR !2](https://git.nju.edu.cn/Tensor4627/AIMatterLab/-/merge_requests/2)，来源提交为 `e57c0928df737c74bf3896ee85e4b91ffd42c02a`。PR 的原版本号为 0.1.2，本地统一升级为 0.1.5；0.1.2、0.1.3 和 0.1.4 的既有记录保留原始版本与验证范围。

## 接入范围与兼容性

- Codex 订阅继续走官方 app-server；Qwen 与自定义 API 改用锁定的官方 DSH 0.2.2-rc.1 和 pi-ai 适配器。Kimi 的 ACP 入口保留。
- 自定义 API 支持 OpenAI Chat Completions、OpenAI Responses 与 Anthropic Messages；Gemini 原生协议、API 图片输入与 DSH 多 Agent 编排未接入。
- Qwen API 模式不再恢复原 Qwen CLI 对话。旧自定义 API 对话只在地址和协议相同的配置下恢复，历史作为文本参考，不重放工具。
- 无密钥模式限于本机环回地址。固定版本的 pi-ai 要求非空 key，运行时使用公开的本机占位值；该值不是用户凭据，不计为已保存密钥，也不会用于远程无密钥服务。
- Codex 登录运行在独立 CODEX_HOME。仅认证连接不挂载科学工具，只允许账号操作和公开模型目录读取；聊天仍需重新建立完整连接，加载并核对模型能力快照。优先读取独立目录的模型缓存，可在普通连接中按原规则复用本机已有订阅登录。
- 保留 SSH 连接、密钥、计算环境、项目授权与真实作业；未修改同级科学引擎仓库。终端冲突保留 0.1.4 的会话所有权检查，同时加入 PR 的明确按键操作。
