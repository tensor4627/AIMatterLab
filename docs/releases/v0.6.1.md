# v0.6.1：启动白屏修复与开发期数据约定

更新日期：2026-10-15。针对 0.6.0 在实际用户配置启动后白屏的问题发布补丁。

## 原因与修复

0.6.0 将 missingFields 中全部字符串作为参数路径校验；旧草稿包含自然语言的待确认条件，恢复流程页时抛出 Invalid field key。没有页面异常边界，导致整棵 React 界面卸载。原先隔离 profile 验收没有覆盖这份实际数据。

现在区分参数路径与自然语言要求。路径仍执行严格字段及原型保护；文字要求直接显示在红点“待确认事项”中，不参与对象路径访问，始终作为未解决项阻止执行，直到 Agent 复核更新。Python present_task 接口采用同一语义，仍严格检查实际参数键及结构化字段。

工作区和应用根部增加异常边界。单页异常显示恢复入口，工作区异常保留导航和 Agent；可返回工作台或重试。新增 scripts/startup-smoke.mjs 验证真实 Electron、实际正常用户配置、版本、界面可见和 renderer 无 Node 权限。

## 数据清理与兼容策略

经用户明确确认，清理本机 Studio 的 12 个旧测试流程、2 个会话和 6 条线程索引；清理仅限本地索引，没有删除服务商原生历史或实际作业记录。其余桌面配置记录与凭据文件清理前后哈希一致，worker 中两个集群登记仍可读。备份和脱敏验证结果留在忽略的运行目录。

开发期允许为显著改进作明确说明的破坏性变更，无需长期保留可抛弃的测试会话。SSH 连接、凭据、计算环境、项目授权与真实作业保持保护；自 1.0 起严格执行向后兼容与版本化数据迁移。该约定已写入 AGENTS.md。
