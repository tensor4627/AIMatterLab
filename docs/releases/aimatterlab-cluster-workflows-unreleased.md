| 首次交接 | passed | 从新手引导登录临时 OpenSSH，查看账号与解析后的总工作区，通过正常确认自动传输并启动作业服务。 |

| 资源工具 | passed | 在同一 SSH 连接打开新手引导里的自定义工具表单，核对程序和目标，确认后由测试队列运行。产物为 88 字节的 extxyz 轨迹。界面返回实际作业号、内容检查、文件摘要和已保存的资源执行技能。 |

| 会话目录与权限 | passed | 核对并发认领、跨日重试、原目录恢复和区外操作确认。在 Linux 上实际执行受限进程，检查工作区、符号链接与子进程的文件访问。 |
| 队列与产物 | passed | 使用 Slurm、LSF 命令夹具运行实际批处理脚本。自定义轨迹工具与内置数密度分析的两步测试核对消费端实际读取的字节。确认后更换工具版本、重开 worker，原流程仍使用冻结版本。 |
| Electron 整图 | passed | 从新手引导的原连接进入工具配置并复用原服务。选定保存的双节点草稿、核对并确认整图后，队列短例分别取得作业号 5002 和 5003。流程以一个数密度样本通过验收。核对了生产与消费的 SHA-256、会话目录及原会话完成消息。草稿由测试数据提供，模型生成步骤未实测。 |

| 原会话开启规划 | passed | 隔离 Node、Electron 和 WSL 检查保留原项目和通道、恢复与撤权竞态、草稿保存、跨日找回及冻结原会话目录。原生窗口中先继续原对话，再核对已有工作目录。核对期间保存草稿和预览都保留作业状态。 |

| 输入区选择 | passed | 从本机 Codex 26.1111.9664.0 的安装包加载原问题组件，在独立 Electron 窗口与 AIMatterLab 的实际对话组件使用相同题目。检查数字键、上下高亮、多题切换、自填和窄屏。 |
