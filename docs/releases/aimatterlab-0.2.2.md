## 建议与实际实现

| 计划 | 结论与依据 |
| --- | --- |
| O1–O2，定位与首帧 | 采纳。使用实际标题栏、可见裁切范围和弹窗坐标系布局。优先放在目标外，放不下时转为紧凑提示并避让关闭按钮。先提交目标文案再测量提示卡，定位完成后显示。 |
| O3–O4，操作与进度 | 采纳。高亮区保留原控件的点击和键盘事件。课节条使用真实设置页或示例步骤，支持 Esc、返回、重新高亮；目标折叠、未加载或被裁到无法操作时显示说明。 |
| O5，真实输入与交接 | 采纳。账号切换或添加服务商后定位新表单的实际输入。SSH 认证阶段优先终端，保留已有手工操作入口。初次打开工作区先检查目录，明确核对后指向确认；再编辑会使目录核对失效。 |
| O6，账号完成出口 | 采纳。独立和向导嵌入的账号弹窗都有固定底栏。入口按已取得的账号状态、未保存编辑和待处理操作显示「稍后配置」「放弃修改并关闭」「完成」或「关闭」。已保存配置和模型测试分别记账。 |
| 工作台拖栏 | 采纳。指针移动更新 CSS 预览与无障碍数值，松开时一次性提交最终尺寸。取消、失去指针捕获和卸载会清理预览。方向键、Shift 微调、Home 和 End 沿用现有行为。 |
| 抽取全部弹窗、下沉资源心跳 | 暂缓。设置编辑、取消、恢复焦点和会话删除都有根组件参与。单独挪走弹窗 JSX 仍会触发其状态所有者更新。托管资源由桌面事件和窗口聚焦刷新，根组件还用同一快照恢复指定资源、定位运行、判断会话是否正在回复。报告假设的轮询不在此 hook 中。 |
| Agent 输入组件 | 采纳。输入组件订阅现有草稿存储，沿用服务商和会话归属；发送在操作时读取最新快照。消息、跟进与附件的真实提交继续经过原有请求路径。 |
| 用单一 Reducer 替换回合状态 | 暂缓。准备发送、桌面观察到的回合、停止请求和未知回执有不同的归属和时序，可同时存在。输入改动已有可重复的收益，目前没有证据支持按 ref 数量重写恢复逻辑。 |
| 超过 150 条后卸载旧消息 | 保留现有每 30 轮历史分页和已加载的 DOM。250 条消息的流式更新检查中，旧节点和滚动位置稳定；完成后原生查找可命中早期消息，跨页选区可保留。卸载旧页会让原生查找和跨页选取失去文本。 |
| 集群详情拆分、四段就绪条 | 采纳。设置和作业详情独立加载。SSH/调度器使用带日期且匹配连接的回执，复查区分失败、未确认和历史观察。队列显示当前项目及连接版本的授权，科学环境标明配置和计算节点的验证范围。各入口可独立访问。 |
| 用 CSS 隐藏 SSH 明文 | 调整实现。Electron 的可访问树仍能读取 CSS 掩码后的原文。改为收起时不挂载真实值，主动揭示后使用普通文本输入，隐藏或切换配置时撤下。 |
| 三处遗留缺陷 | 两项修复。设置端口的空值与非法值仅作为编辑草稿，错误提示保留在设置内。桌面确认删除后的内存清理独立于浏览器存储，科学参数和部署草稿的迟到保存不会恢复已删除任务。续算清理标题已由共用 Modal 翻译，本轮补做英文实窗回归。 |
