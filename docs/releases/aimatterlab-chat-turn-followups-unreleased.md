# 会话排队、引导与中断续发

2026-11-22。基于 0.1.29 的开发分支，沿用现有包版本。

回复进行时，默认按 Enter 排队，Ctrl/Cmd+Enter 引导，Shift+Enter 换行。在「Agent 选项」可以对调排队和引导的快捷键。Codex、DeepSeek、Qwen 和自定义 API 支持文字引导。Kimi 的 ACP 适配器提供排队。附带技能的消息按下一轮输入处理。

排队消息保存在原对话，可以取消、移回草稿或转为引导。当前对话按收到完成回执的顺序逐条发送。切换对话后，原队列等用户返回再推进。主动停止后可直接续发，也可单独恢复队列。重开窗口后可以恢复已保存的队列。发送结果未知的条目保留给用户核对。

DSH 通过仅父子进程可用的控制通道操作正在运行的原生回合。中断保留原会话、已输出的文本和待发送的新草稿。旧回合的完成或错误通知依据回合 ID 处理。停止回复只作用于模型交互，已提交的计算作业由原 worker 或调度器管理。
