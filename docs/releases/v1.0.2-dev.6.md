# 1.0.2-dev.6：退出时断开终端与删除保存连接

2026-11-11，用户明确要求正常退出 Studio 时自动断开连接，重新打开后建立新连接，并报告保存的计算资源连接无法删除。本代将交互式 SSH/本地终端改为桌面会话内复用，并补上保存连接的删除入口。已提交计算作业继续由 worker 管理，不随桌面退出取消；科学引擎不变。

## 行为调整

- 正常退出先禁止新的界面与终端操作，再等待当前桌面自己的终端关闭；退出等待有上限。重新启动后不再附加上次终端，不因上次未知连接或未确认打开记录阻挡本次新连接。用户仍需选择保存的连接，不自动登录或代输密码。
- 后台描述符按桌面会话隔离，使用加密的版本 2 格式。旧 `broker.bin`、版本 1 索引及旧会话保留为诊断历史，不连接、不接管、不杀死历史后台。旧桌面中已存在的终端不会被本次开发测试操作。
- 当前桌面内依然保留重复点击去重、打开结果不明时不自动重试、人工/Agent 交接及原连接版本检查。退出过程中迟到的准备/打开操作不能创建未受管理的终端。
- 新增保存连接的删除和确认入口。删除仅移除桌面保存项，不删除密钥、计算环境、项目授权、服务或真实作业。当前桌面正在使用或正在打开的 SSH 保存项须先断开；WSL 保存项删除不终止已连接的作业服务。删除须匹配当前版本，旧确认不能删除后来编辑的连接。
- 删除最后一个自动登记的本地连接后，通过版本 1 注册表标记防止它在下次启动时重新出现。上次终端的界面资源选择在新桌面启动时清除；已注册环境、worker 来源和任务绑定不改。
- dev.5 的 Codex CLI 版本差异 warning 策略及此前四项问题修复继续保留。旧 dev.5 跨桌面终端保持验证属于历史行为，本代明确改变该产品规则。
