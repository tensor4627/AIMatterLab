## 兼容性与验收边界

- 项目可以显式设置 `gpus: []`。既有 GPU 清单继续按实际值使用。布尔值等非法旧值在用户明确修复后按类型保存。既有连接、凭据、环境和运行记录不需要批量迁移。
- 新的手动核对回执保留当时的作业投影。旧回执缺少这份证据时可查看原作业的当前记录，本次历史观察显示未确认。
- 桌面离线停止与当前会话的 Agent 停止分别核验。缺少发起方证据的旧停止意图保留在原计划上，待明确确认前暂缓该计划的新轮次。旧委托缺少用途证据时，只对新 Agent 操作重新取得对应指示。
- 内置诊断索引描述第一方可定位的发出点及其分支。13 个多原因出口标注了所需的上游回执。动态生成代码、外部程序任意错误文本、实际出现频率与每条静态分支的生产可达性各有独立边界。

Node 与索引复点证据在忽略目录 `validation/local/diagnostic-audit/`，原生表单及运行记录证据分别在 `validation/local/diagnostic-cpu-authorization-native/` 和 `validation/local/managed-compute-20261119/native-renderer/`。
