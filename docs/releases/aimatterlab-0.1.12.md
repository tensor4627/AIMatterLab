# AIMatterLab 0.1.12

2026-11-19 · Windows x64 · [私有仓库源码标签](https://github.com/tensor4627/AIMatterLab/tree/v0.1.12) · [更新日志](../../CHANGELOG.md)

## 个人库与内置指南

首次启动从安装工作区定位个人库。便携版、源码版和选择了自定义缓存的用户使用各自生效的缓存位置。桌面把个人库绝对目录填入内置 `AGENTS.md`，新会话收到同一套查找、读写和读回规则。「把技能存到本机工作区」使用 `scope=user`。调用目录返回 `directory`，读写返回 `SKILL.md` 的 `path`。

个人、项目和私有会话技能使用桌面本地技能工具。内置指南通过独立的科学功能目录和文档标识读取。个人技能与内置指南对同一步提出互斥操作时，主提示词要求 Agent 指明两份技能和分歧，等待用户选择流程。选择仍遵循项目与计算资源已有授权。[技能库和调用说明](../project-skill-workspace.md)

## 提示词与目录复查

- 输入与建图详细指南提供按需入口 `workflow.authoring`。总流程仍由 `workflow.orchestrate` 提供。
- 工作流编写说明明确了普通对话可以保存个人技能。工作流中的持续执行提示也保留了对技能冲突的用户选择。
- 手动搜索范围包含个人库、项目库或迁移保留的原目录时，通用目录会跳过这些私有条目。内置目录和技能缓存分别存放。

旧版兼容 API 账号表单沿用公开的模型、端点和推理设置回显，密钥仍由凭据库管理。从 GitHub 上的 0.1.9 升级也会包含 [0.1.11 已验收的工作台与聚焦引导](aimatterlab-0.1.11.md)。
