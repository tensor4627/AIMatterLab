# AIMatterLab 0.1.13

2026-11-19 · Windows x64 · [更新日志](../../CHANGELOG.md)

## 使用计算资源

在「连接计算资源」保存并登录 SSH，看到远端终端后点击「登录完成，交由 AIMatterLab 管理」。可以继续登录其他集群。进入「设置 → 计算连接」查看托管的资源、配置作业服务，以及管理当前项目的终端使用权限。作业服务会另外核对 worker 身份和远端项目权限。用户处理个人凭据和站点二步认证。

会话可以列出资源并按指示申请。不同会话使用独立的远端终端，同一会话可以同时使用多个平台。当前每条 SSH 主连接最多分配 4 个会话通道，另外保留程序作业服务通道。站点会话配额较小时，界面会显示远端拒绝分配的原因。首次提到有歧义的集群名称时，选择实际连接。确认后的惯用名保存在本地个人 skill 库中，关联稳定的连接配置。SSH 子终端各有自己的当前目录、变量和前台进程，文件操作遵循远端用户实际权限。

会话栏的长方形徽记记录已使用的资源。本地资源显示 `local`，SSH 使用连接名称。已确认的运行作业启动该资源的徽记动效，类型可在「设置 → 外观」切换。会话行尾的转圈表示 Agent 正在处理本轮消息，圆形时钟表示有待触发的 Agent 唤醒。

## 有限次作业服务

可在已有任务授权内要求定时巡检、挂载临时脚本或到时唤醒原会话。默认间隔为 30 分钟、最多 48 轮，一份委托最多 336 轮。每个计划都有截止时间、单轮超时和原服务身份。通用脚本提交到父任务获准使用的 Slurm 或 LSF 队列，由调度器管理子作业。

在「运行记录 → 定时任务」核对创建会话、源平台、余额、下次触发和执行记录。点击「终止计划」会先停止新轮次，再核对本轮子作业。离线停止会保留「停止待远端确认」，重新连接原服务后继续处理。关闭窗口进入托盘，明确退出暂停新派发，已经提交的计算作业由原调度器维护。

巡检达到额度上限时，如果原作业仍然排队、运行或没有取得终态回执，工作台会显示一次关注提醒。后台运行时也会尝试显示系统通知。点击「查看运行记录」可定位原平台的计划、作业号和最后已知状态。「手动核对一次」只检查该作业，不增加自动巡检轮次。

## 兼容性

本版基于本地 `v0.1.12`。沿用已有连接配置、用户缓存、个人 skill、凭据引用和运行记录。活跃 SSH 资源需要用户在本次登录后确认托管。有限次计划需要具备对应能力的作业服务，旧服务可在原资源设置中核对并更新。
