# v0.11.0 · 第一轮：科学流程与部署分离

本轮是源码里程碑，最终便携包在第三轮统一验收，不为未打包版本建立发布标签。

- 新会话使用 workflow v2：先定义引擎、输入文件、MD/CV/bias 等科学条件，再完成科学参数复核；不再要求提前选环境或生成作业。
- 新增独立“部署与执行”模块，集中设置算力、工作目录名、队列、资源和墙钟时长；配置调整保留科学复核，但废弃旧部署快照。执行前再次核对科学版本和部署版本。
- MetaD/WTMetaD 默认单任务、单 walker；两个采样引擎都明确拒绝未实现的多 walker。多个 CV 仍是一项采样。
- 部署展示不可变输入哈希与实际文件预览，并要求人工核对；科学元数据改变但实际文件未更新时拒绝部署。已声明的 GPUMD 步数、恒温值、时间步长与 run.in 冲突时拒绝执行；任意 Python 驱动的语义绑定仍 not_run，不冒称自动证明。
- 新增受限远端输入快照与终态回收的后端基础：512KiB分块、128MiB上限、授权根/symlink约束、SHA核对、稳定资产ID。集群界面与真实短算在下一轮接线验证。工作目录使用安全前缀和唯一run ID。
- 监督 agent 提出的 unknown 恢复、实际输入一致性与工作目录问题已处理。旧开发会话沿用旧流程；新会话默认v2，SSH、凭据、环境与真实运行记录不删除。
