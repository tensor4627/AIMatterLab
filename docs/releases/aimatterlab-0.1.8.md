# AIMatterLab 0.1.8

2026-11-17 · Windows x64 · [更新日志](../../CHANGELOG.md)

0.1.7 用户先退出桌面应用，运行 `AIMatterLab-0.1.8-win-x64-setup.exe` 并选择原工作区。此后可点击标题栏版本号，或进入「工作台设置 → 软件更新」。工作区窗口打开后也会在后台检查一次。发现新版时显示下载方式、所需流量与进度。点击「重启更新」后，安装器先确认目标工作区，再通知当前应用退出，安装期间显示等待提示，完成后重新打开软件。

安装器把当前版本的完整安装包保存在 `user-cache/updates/installer.exe`。差分下载从中复制可复用的数据块，通过 HTTP Range 请求获取变化的部分。失去基准、块索引不可用、服务器不支持 Range 或重组校验失败时，面板会提供完整包及其大小。已下载的更新可在离线重开软件后继续安装。安装器按原工作区的程序文件清单操作，项目源码、账号配置、技能和提示词继续由原工作区管理。源码和直接解压的 ZIP 仍可使用原有启动方式，应用内更新入口会提示使用工作区安装版。

## 后续版本的分发

1. 在发版机运行 `pnpm run pack`。Windows 发布签名使用当前用户「个人」证书库内与 [发布证书](../../contracts/update-publisher.pem) 对应的私钥。使用证书管理器保管受密码保护的私钥备份。此版本使用项目自签证书，Windows 的公共发行商信任取决于其证书链。客户端使用内置公钥验证清单，再校验完整安装包的 SHA-512。
2. 在项目的 GitHub Releases 中创建对应版本的草稿，例如 `v0.1.8`。将 `release/v0.1.8/` 中同次构建的 `AIMatterLab-0.1.8-win-x64-setup.exe`、同名 `.exe.blockmap` 和 `latest.yml` 一起上传，再发布为最新正式版。分发 ZIP 和 `SHA256SUMS.txt` 也在同一目录。打包命令仅生成本地文件。
3. 保留各已发布版本的安装包与块索引。客户端按正在运行的版本及目标版本获取各自的索引，可直接跨版本更新。需要修订已经发布的二进制时使用新版本号。首次换签前应通过仍受旧密钥信任的版本预置下一把公钥。
