# AIMatterLab 0.2.9

科学助手优先采用随包技能和当前工作区资料，也可同时查询公开来源，补足证据或核对版本差异。`search_scientific_literature` 通过 Crossref 返回可核实的题录、DOI 和出版信息，`read_software_docs` 可读取公开论文页及固定版本的上游手册。只按名称或版本调用 `search_software_docs` 会查询本地发行清单，未收录时也保持离线。需要查 GitHub 和 PyPI 时，助手可以直接指定 `sources="public"`。用户明确要求离线或只用内部资料时，只采用内部证据。

DeepSeek V4.1 Flash 通过官方 DSH 连接。应用之前将启用思考时的单次输出限制为 32,768 token，关闭思考时限制为 8,192。现在由官方适配器按所选模型决定。自动压缩为后续请求腾出上下文，单次生成仍遵循模型的输出额度。Codex 的通用 MCP 资源、模板查询现支持省略服务名，空目录也可继续进入科学技能。[官方 DSH 上下文压缩说明](https://github.com/deepseek-ai/deepseek-harness/blob/master/packages/compaction/compaction-basic/README.md)

## 运行时和随包指导

- 工作区升级按最长已知的完整旧指引保留用户笔记。Windows 安装版依清单部署当前 worker 与终端组件。复演时在安装目录放入 33 个历史 Python 文件，升级保留了这些未登记为安装器所有的文件，实际 worker 指纹和 WSL、SSH 部署文件清单均排除了它们。流程绑定、恢复会话和返回普通聊天时按当前授权刷新 DeepSeek 工具清单。
- 复核运行时 `AGENTS.md`、工具发现、产品指引、科学函数表及模型的首次、恢复与流程轮次提示。更新 GPUMD 原生输入输出、NEB、固定伞窗、良调元动力学、OPES、pyGAS、TorchNEP 和 HotHam 的来源、参数、环境、资源估算与验收说明。
- 内置指南提供与发行版本匹配的引用，来源回执可区分 Git 的规范文本、已核实的 Windows 检出字节与实际内容差异。逐题的会话和逐文件的原始回执保存在忽略的运行目录。
- 普通聊天中的 `analysis.wtmetad` 可交付随包的 WTMetaD 原理与 DOI，已获准的会话可按原文档 ID 继续读取 pyGAS 源码参考。GPUMD 的指南区分 NVE 有界能量误差和长期漂移，列出固定物理阻尼时步数随步长的换算。pyGAS 指南说明原生 `GAScfg.yaml` 键值分隔符及其解析行为。

## 正式标签的科学问答

五道独立场景分别考察 MD 平衡密度、固定伞窗自由能、双副本 WTMetaD、非正交电子能带和 LCAO 哈密顿量训练。每题都要求说明科学方法、参数、资源、环境、从输入到结果的执行流程及验收。题面由 GPT-6.2 Sol High 拟定并锁定。两种模型在源码版及真实 NSIS 安装载荷各自的全新会话作答。评分只看可见终稿，另外按工具回执的文档 ID 和 SHA-256 核对实际读取。

DeepSeek V4.1 Flash 使用官方 DSH 的 Max 档，GPT-6 Luna 使用 Medium。20 格均已提问，18 格有终稿。正式安装版 DeepSeek 的 WTMetaD 和哈密顿量题均在读取对应技能前收到服务端 `Insufficient Balance`，这两格记为 `blocked`。同一安装模型的普通书目题收到相同错误，随后离线书目题未发送。前一签名候选的四组普通和离线书目对照，以及两组并行内外交叉验证和两组通用 MCP 目录复核，均保留其原构建身份。

六个维度各计 0–2 分，满分 12。18 份终稿均经匿名盲评并逐句复核，2 份完整、14 份部分满足、2 份有重大错误。盲评请求了 Ultrafast，服务端实际档位未独立确认。

17 份终稿有相应专题参考文件的实读哈希，包括 GPUMD 原生输入、固定伞窗、WTMetaD 和 HotHam 指南。安装版 Luna 的能带答复读取了公开上游材料，提交的内置文档 ID 无效，该答卷没有内置 HotHam 专题文件的成功回执。

源码 DeepSeek 的 MD 示例按其 ASE 建胞指令得到 1,024 个原子，随后对 4,096 个原子的断言会失败。安装版 Luna 指定 GPUMD v5.9.1，却把初始化命令写成 `velocity 300 12345`，缺少 `seed` 关键字。两者都已经读到对应 MD 科学技能。安装版 Luna 的另一组独立书目问答从 Crossref 查证了 Barducci 等原始论文，离线提问时读取内置 WTMetaD 指南，外部调用为零。[WTMetaD 原始论文](https://doi.org/10.1103/PhysRevLett.100.020603)
