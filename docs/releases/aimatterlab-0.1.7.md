# AIMatterLab 0.1.7

2026-11-17 · Windows x64 · [更新日志](../../CHANGELOG.md)

Windows 主分发文件为 `AIMatterLab-0.1.7-win-x64-setup.exe`。安装时选择可写工作区，程序文件直接解压到根目录，桌面快捷方式指向其中的 `AIMatterLab.exe`。Windows 已安装的应用列表提供卸载入口。独立 ZIP 继续提供。

| 工作区内容 | 用途 |
| --- | --- |
| `AIMatterLab.exe`、`resources/` 等 | Windows 桌面程序及其运行依赖。 |
| `.config/` | 桌面配置、凭据、连接信息和作业索引。已有安装选择原配置的父目录可继续使用。 |
| `sources/` | 用户放置的科学软件源码。工作台按启用的源码类型识别本机检出，计算环境仍按原登记使用。 |
| `user-cache/` | 新工作区的 Chromium 会话数据与默认的 `skills/` 库。旧工作区沿用已有浏览器会话，用户自行配置的技能缓存路径优先。 |
| `AGENTS.md` | 可编辑的工作区索引。每个绑定项目的提示词与该项目的本机技能放在同一目录，按相对路径引用对应技能。 |

[用户技能与项目提示词说明](../project-skill-workspace.md)

## 兼容与数据保留

旧版单文件启动方式由安装向导取代。已使用过的工作区可在安装向导中再次选择。安装器从实际打包目录生成程序文件清单，卸载时按清单删除文件，仅移除已经空的程序子目录。工作区原有的 `AGENTS.md` 和用户补充的文件会保留。升级遇到另一个正在使用的同名程序时，按选择的工作区定位可执行文件。

项目提示词随项目技能库迁移。发生内容冲突时，旧目录继续可用。未绑定项目的对话沿用其私有技能库。保存个人或项目技能时只追加相应链接，已有项目约定可继续编辑。
