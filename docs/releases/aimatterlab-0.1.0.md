# AIMatterLab 0.1.0

2026-11-14 · Windows x64 · 开发分支 `dev`。AIMatterLab 从 GPU Sampling Studio 1.0.2-dev.33（`35882d7`）开始独立版本序列。它沿用可审阅的工作流、显式计算环境和由 worker 维护的作业记录，新增正式面向第三方软件开发者的工具交付入口。[产品规范](../software-specification.md)

## 获取与使用

- Windows ZIP 解压后双击 `AIMatterLab.exe`。单文件便携 EXE 启动时先解压。两种发行方式使用同一桌面程序。
- 使用本机 Agent 从源码安装时，可以复制[单 prompt 安装提示](../one-prompt-install.md)。从新目录按文档命令通过 HTTPS 克隆仓库，检出已验收的源码 `27793f5` 并运行 `plan` 已通过。该检查覆盖源码获取、版本核对与安装计划，目标机登录和科学短例仍需在用户选择的环境完成。
- 从「工具与资源 → 第三方工具包」选择开发者交付的 `<id>-package` 目录。桌面检查 Git 提交、工具声明和文件内容，然后登记可追溯的版本。已有「技能库」入口也可访问同一面板。
- 同一页面的「已验证工具的源码仓库」列出 GPU-Sampling、pyGAS、PyDyn、TorchNEP 和 HotPP 的克隆命令及仓库内安装文档。清单也随 Windows 包放在 `resources/tool-sources.json`。[源码清单](../../installation/tool-sources.json)
- 独立开发者 ZIP 提供 `tool.json` v1 规范、声明检查器、交付指南和 CPU 示例生成器。示例可在解压目录中生成和检查；用户选择授权项目和环境后，固定串行 CPU `installation.check` 适配器可安装、测试、生成执行技能并启动新作业。其他工具可登记定义，运行支持取决于对应适配器。[开发者快速开始](../../developer/README.md)
- `pnpm run pack` 将桌面 ZIP、单文件 EXE、开发者 ZIP 和 `SHA256SUMS.txt` 写入 `release/v0.1.0/`。本地 Windows 成品未签名。

## 命名与兼容

桌面标题、中英文界面、设置页、安装元数据、程序与压缩包文件名、服务商显示身份和开发者交付模板使用 AIMatterLab。软件包名为 `aimatterlab`，发布版本为 `0.1.0`。按旧文件名查找 EXE 的脚本需要更新。GPU-Sampling 继续作为科学引擎名称使用。

应用 ID、配置目录、数据库、连接和授权标识、worker 认证身份及旧记录的读取规则延续上一代。原生升级验收在旧版新建隔离 SSH 登记并保存界面设置，新版从同一目录读回相同的登记版本和设置。默认测试配置另行备份，开箱检查从空目录开始。[命名与数据兼容说明](../development/product-naming.md)

## 体积与速度

比较基线为同机的 GPU Sampling Studio 1.0.2-dev.33 Windows x64 成品。旧 ZIP 使用与本版相同的 electron-builder 压缩方式从原成品重建。MB 为十进制。

| 指标 | GPU Sampling Studio | AIMatterLab 0.1.0 | 降幅 |
| --- | ---: | ---: | ---: |
| Windows ZIP | 363.0 MB | 197.8 MB | 45.5% |
| 解压目录 | 1,071.6 MB | 529.8 MB | 50.6% |
| 解压文件数 | 65,819 | 22,928 | 65.2% |
| 首屏入口 JavaScript | 1,092,066 B | 741,624 B | 32.1% |
| 图表 JavaScript | 1,043,143 B | 522,654 B | 49.9% |
| 启动进程至首屏可交互，中位数 | 396.5 ms | 379.0 ms | 4.4% |
| 官方 DeepSeek Harness 握手，中位数 | 1,156.9 ms | 944.6 ms | 18.4% |
| 本地目录批量读取，中位数 | 163.6 ms | 145.9 ms | 10.8% |

- 两版解压成品各预热一次，随后按轮交替启动各八次。每次使用新配置目录，系统文件缓存已预热。从创建进程到渲染器报告可交互，旧版范围 359–409 ms，新版 354–450 ms；单次结果有重叠。单文件 EXE 的首次解压另做开箱验证。
- 官方 DeepSeek Harness 固定在 `0.2.2-rc.1`。只暂存工作台启用的 SDK 模块、其依赖和许可证，含清单的体积从 722.9 MB 降到 182.3 MB。握手测试使用相同 Electron 运行时和本地模拟模型目录，每版五次。目录读取采用 100 个草稿、每样本 1,000 批读取，两版的结果校验值一致。
- 终端面板和 xterm 在首次使用时加载，同一会话中切换页面或运行队列可保留已挂载的终端。图表按实际使用的折线、图例和缩放组件加载。原生图表交互已验证图例切换、滚轮缩放。
- 清理了无调用的旧模块与发行包中的开发类型声明。按相同目录和扩展名统计自有运行源码，Git 规范化字节从 3,689,308 降至 3,686,310；范围涵盖桌面、前端、Agent、后端和契约中的 JS/TS/Python，排除生成物、声明、文档、测试和构建脚本。体积收益主要来自依赖和构建产物。
