# AIMatterLab 0.1.9

2026-11-18 · Windows x64 · [更新日志](../../CHANGELOG.md)

计算流程图用不同的轮廓、图标和颜色区分输入、工具与输出。图上显示简称，悬停或键盘聚焦可读全称，打开节点可查看端口、文件和交付要求。已有流程会自动生成简称。

切换 WSL 与 SSH 时会保留最近一次选择，集群基础工作区可以复用。可将结构、势和控制文件成组复制到流程工作区并核对来源。作业列表的筛选更紧凑，查看与撤销作业时会核对所属服务及身份。Agent 迟到的回复回到原会话，复现包补全了输入快照、运行命令和环境信息。

## 下载与升级

使用有仓库访问权限的 GitHub 账号登录发行页。Windows 工作区用户退出应用后，运行 `AIMatterLab-0.1.9-win-x64-setup.exe` 并选择原工作区。便携用户将 `AIMatterLab-0.1.9-win-x64.zip` 解压到新目录。开发者工具包单独提供，下载文件可用同一发行页的 `SHA256SUMS.txt` 核验。[GitHub 下载](https://github.com/tensor4627/AIMatterLab/releases/tag/v0.1.9)

桌面更新器匿名读取更新清单。当前仓库按私有权限分发，0.1.8 工作区升级到本版请使用上述安装包。

安装包 SHA-256 为 `18c95e52d636bd81dd26bc13bcb5c65428d14d4f31cedd73f0167c0d34f30c27`。安装包和更新清单使用项目自签证书，Windows 对该证书的信任取决于本机证书库。
