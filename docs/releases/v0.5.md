# v0.5：规划开关、SSH 用户名与 One-prompt 安装

更新日期：2026-10-14。便携程序：release/GPU Sampling Studio 0.5.0.exe。

## 修复

Agent 默认普通对话，只有显式开启“任务规划模式”才创建中央流程参数页。每轮发送当前模式，返回普通聊天时解除旧任务绑定；开关在请求运行中不可切换。参数连续回填采用递增版本，避免同一毫秒的更新漏刷。present_task 使用明确顶层 schema，工具失败不作为参数已保存的证据。

SSH 主机、用户名和端口分别设置，旧 user@host 可拆分，用户能主动修改用户名。worker 与桌面终端都用 -l 强制指定远程用户；缺少用户名直接阻止，不回退 Windows 用户。增加保存前只读连接测试，验证实际远程用户，返回脱敏状态。

## 安装入口

根目录 INSTALL_AGENT.md 可交给通用本地 Agent。scripts/one_prompt.py 提供 plan / configure / target-probe / smoke / desktop / finalize，含独立 venv、完整 commit 的源码注册、私有日志、环境复用、LSF/Slurm 草稿和审阅后短例、独立桌面 profile 和启动文件。finalize 要求当前源码/配置对应的检查及全部选定短例通过。说明见 one-prompt-install.md。

首版提供进程生命周期、ASE reference MD 与真实 PyDyn CUDA MD。额外训练、采样和 GPUMD fixture 尚未内置，选中时 blocked。GitHub 发布 URL 暂为空；当前以完整本地 checkout 验证，不虚构线上发布。
