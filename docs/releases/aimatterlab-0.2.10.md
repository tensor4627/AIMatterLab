# AIMatterLab 0.2.10

本轮从 0.2.9 本地签名构建开始，优化 Windows 安装与更新。集成保留 v0.2.9 的源码提交及随后的 GitHub DSH 验证补丁。0.2.8 用作性能计划的对照版本。

## 安装和更新改动

- Windows x64 运行时暂存的程序文件从 30,566 个减至 5,730 个，降幅 81.25%。DSH 的六个 esbuild bundle 保留官方入口以及动态加载的扩展和资产。终端的 `@lydell/node-pty` 只携带 Windows x64 原生包。第三方许可文件随依赖保留。
- 差分最多同时下载五段。间隙上限为 128 KiB，单个区间上限为 8 MiB。在相同 0.2.8 → 0.2.9 载荷和 150 ms 本地模拟延迟下，新算法以 8 段、3,765,509 B 在 1,060 ms 重组出相同安装器。此样本多传输了 41,719 B。
- 全量包在下载时累积 SHA-512。安装前用进程内已验证的文件身份确认缓存，文件变化或跨进程恢复时重新校验。NSIS 自更新直接提升 `pending.exe`。若 NSIS 持有安装包造成 Windows 共享冲突，安装成功后的下一次应用启动再将该文件原位改名。
- `appPayload` 采用单独的签名字段。适配的工作区保留原 NSIS 差分基准，仅替换受管应用文件。新版启动失败或辅助进程意外退出时，基于事务和备份恢复。以 0.2.10 为起点，同一 ABI 的后续版本可以采用这条路线。

## 发版复核

- 程序成品来自提交 `01b905a`。发版补充提交更新版本说明和下载入口，成品沿用已验收的签名构建。
- 逐项核对 13 个内置 skill 和全部引用文件、科学功能映射、启动指导和逐轮提示。这些指导沿用 0.2.9 的内容。核对了技能选择、普通聊天、流程和会话恢复的当前工具入口，以及更新面板的应用包、差分和安装器回退状态。
