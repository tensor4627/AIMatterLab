# 1.0.2-dev.24：助手文字布局、默认字号与会话分组删除

根据用户在 dev.23 的实际截图修正三处界面，并增加侧栏会话分组删除。没有改动科学引擎、计算参数、计算授权或作业执行规则。

- 助手标题栏从固定高度的换行 flex 改为自动高度的两列 grid。会话标题与操作位于首行，模型摘要独占第二行，连接提示在标题栏后正常排列。长摘要省略显示，提示正常换行。
- 移除“Agent 会话与科学计算队列独立运行”及空侧栏的“对话会自动保存在这里”。搜索无匹配仍有准确提示。
- 默认界面 / 对话 / 代码字号 13→18 px（约 +38%），默认最小字号 12→17 px（约 +42%），默认终端 12→17 px。外观设置显示相同默认值；已有自定义值优先，不写回或覆盖个人设置。
- 每个会话分组的加号右侧增加三点菜单，支持删除确认与取消。删除后会话移至未分组，保留置顶、会话、关联流程和真实运行；不删除计算项目。

新增 `conversation.deleteGroup` 类型化请求 / 结果及 preload 白名单，沿用主进程 sender 校验和 Agent 空闲保护。Catalog 事务统一解绑会话、删除分组并记录删除身份；事务错误完整回滚，重复删除幂等。迟到的 remember 请求不恢复已删除分组，显式移入已删除分组仍拒绝。前端不切换会话身份、清空草稿或发起计算。持久化格式保持兼容，仅增加 Catalog 记录种类；无需迁移既有数据。
