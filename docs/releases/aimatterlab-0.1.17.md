# AIMatterLab 0.1.17

2026-11-19 · Windows x64 · [更新日志](../../CHANGELOG.md)

## SSH 托管与终端

完成 SSH 登录后，点击终端工具栏的托管按钮。桌面的发布回执和资源清单使用相同的连接 ID、配置 ID 与配置版本，前端可立即确认本次操作。首次托管、并行点击及重新确认都指向原连接。Agent 继续通过资源 ID 发现资源，按会话及项目权限申请独立通道。

连接状态和常用按钮集中在终端顶部。较少使用的操作收进「更多」，真实错误可以展开查看原因并从原连接恢复。作业服务是否就绪单独核对。
