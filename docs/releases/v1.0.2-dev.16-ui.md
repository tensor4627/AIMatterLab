# 1.0.2-dev.16 前端补充：会话侧栏悬浮菜单

2026-11-12，独立于同代交互登录修复的前端调整。当前为源码变更，未生成新便携包、提交、标签或推送。

## 行为变化

- 会话右侧使用省略号按钮打开圆角悬浮菜单，取代原生 `details` 展开的三角和内联操作区。菜单置于页面顶层，打开时不挤动列表，靠近窗口边缘时自动调整位置。
- 重命名、置顶／取消置顶、移动到项目和删除保留原处理接口。移动项目在同一浮层内选择，当前项目有勾选；删除仍须确认。
- 移除会话名称前的圆点。项目内会话比普通会话缩进 22px，长名称保持单行省略，增加统一行高和悬停／选中背景。
- 支持外部点击、Escape、滚动／调整窗口关闭，方向键、Home／End 导航以及焦点恢复；适配深浅主题、大字号、窄侧栏和长项目列表。

会话存储格式、计算资源与授权契约未改，无需数据迁移。现有会话、连接、凭据、注册环境和真实作业不作迁移或清理；科学引擎仓库未改。
