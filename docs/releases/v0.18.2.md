# v0.18.2 · 第二轮：围绕会话、流程与任务的工作区

本代落实[交互设计基线](../design/interaction-design.md)：把日常对话、当前计算流程、最近工作和任务状态前置，工具与配置进入对应层级。以下软件、科学短例和实际包验收分别记录；原始证据保存在 ignored `.studio/v0182/round2/`。

## 使用方式

- 侧栏保留“工作区、任务、工具”三个主入口；“新对话”始终可见，历史会话按项目组织、独立滚动并可搜索。工具页分为计算与建模、数据与分析、算力与管理。
- 普通对话使用主要空间。当前对话和流程可选择优先布局；窄窗或大字号时用固定按钮切换面板。同一当前流程、Agent 输入框和终端保持实例，切换页面不清空编辑或未发送内容。
- 新用户的底部面板默认收起；已有宽度、高度和展开偏好继续恢复。日志和终端由用户展开，大字号队列说明可换行。
- 两种优先布局保持同样的侧栏宽度；长项目名与会话名省略显示，完整标题仍可查看。大字号不再继承旧对话布局的 180 像素窄侧栏。
- 流程首屏展示最多六个原生基础参数及单位，点击直接定位编辑；高级阶段配置收进展开项。已有基础/细节分组、缺项定位、pyGAS 真实类库、人工复核和明确执行继续保留。
- “任务”统一查看本地与集群保存的运行记录，可按位置、状态、项目、创建时间和文本筛选；能明确找到唯一所属流程时可直接返回会话。读取记录的时间不等于调度器或计算节点的实时观测。

## 保存与连接恢复

项目、环境、资产、本地作业、集群记录和 GPU 查询分别处理失败。保留成功读取的内容及观测时间；单一来源失败不把其他来源清空。连续三次只读失败后暂停该来源的自动查询，用户可以同步或重新连接。首次列表尚未返回时显示待核对，不显示虚假的零任务。

流程状态与嵌套日志采用有界查询；断连或切换作业后丢弃迟到结果。日志按实际返回的字节偏移续读，每个响应只追加一次。保存、准备、提交和续算均不进入自动重试。

作业服务离线时，桌面本地流程参数仍可查看、修改和保存，执行前需重新核对。当前页面已加载的 pyGAS 图可在本机保留修改，重连并检查源码/文件身份后才可保存图文件；未加载过的真实类库仍需连接。显式重新载入失败时也保留草稿，不能先清草稿再报告断连。此范围不包含完整离线聊天缓存或离线模型访问。

同一 renderer 内，相同流程共享尚未完成的保存操作。离开会话再返回时，旧保存确认不会清除较新的手工输入；新视图只等待已经开始的保存，不自动重发失败写入。这不是跨窗口事务同步。

## 范围与兼容性

没有数据迁移、旧会话清空、项目权限扩张或引擎源码修改。保留 SSH、凭据、登记环境、项目范围和真实作业状态。未知提交仍先核对原作业，不能自动重提。

本轮实际 UI 限于零新模型 turn 的操作与恢复，不证明新自然语言规划质量或模型速度提升。实际 Electron 使用中文；英文补验为合成 renderer，不计作实际英文账户/桌面验证。新账户登录、新 SSH 提交、远程调度器实时查询、新机器安装、Materials Project 实查、AOTI 和其他服务商新推理均 not_run。完整离线聊天、会话归档/重命名、工具固定及专门的科学语义摘要仍是后续方向。TorchNEP、NEPMaker、ActiveMiao、外部 DFT 和 PyDyn NEB 的 Studio 执行适配器仍未实现。

软件检查的初始失败、旧选择器适配和修复后结果分别保存。实际 UI 中，两次探查被源码指纹变化或包含隐藏历史详情的过宽选择器中止；均未伪造通过，后继使用同一已保存流程继续。初次使用的新默认底栏与旧配置保留的 190 像素底栏分别验证。

末次大字号检查的初始截图早于异步会话选择完成，因此只作为布局几何证据。后继等待所选会话、保存的会话身份与可见流程标题一致，再记录最终截图；不把旧流程截图计作新流程恢复成功。

实际解包版补验了 PyDyn 会话切到 GPUMD 会话后立即打开流程：无需第二次纠正点击，最终所选条目、保存的会话身份与可见流程一致，两份流程和已有运行记录保持原样。该有界场景不代表排除了所有并发竞态。包测试的首个观察器错误假定连接前一定尚未读过记录，失败后保留原证据并改为按实际状态记录：解包版实际捕获首次读取前的问号状态并通过核对；便携版在观察前已经读取完成，其首次等待状态为 not_observed，不计为验证通过。发布控制文件的状态枚举错误也保留为未启动的测试配置失败。

同一 1100×760 窗口、13 像素正文和 12 像素字号下限下，实际导航比较从旧版 14 项一级入口、历史列表被挤出视野，变为 3 项一级入口、4 条可见历史以及可见的新对话按钮。该比较只针对同一测试会话列表的侧栏，不推断不同计算页面的整体效率。最终大字号侧栏样式作为独立修正重新构建与打包，保留先前源码及候选包的证据。
