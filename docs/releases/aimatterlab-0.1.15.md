# AIMatterLab 0.1.15

2026-11-19 · Windows x64 · 基于本地 `v0.1.14`（`2a27837`）· 本地交付 · [更新日志](../../CHANGELOG.md) · [软件规范](../software-specification.md)

## 用户可见的变化

- 项目可显式授予零个本地 GPU。固定 CPU 安装检查和轨迹数密度分析按实际环境、输入、时限和并发数准备，GPU 引擎按具体设备授权。
- 托管服务分别报告首次配置、功能缺失、项目目录读取失败和实际权限不足，并给出原资源上的处理入口。已具备的终端和索引读取能力可以继续使用。
- 定时巡检、读取日志、运行脚本、唤醒和停止各核对具体用途。作业编号相似或跨资源同号时，需定位完整的原作业。
- 可信桌面的离线停止可在原服务恢复。会话发起的停止保留本会话的权限边界。旧版来源不明的停止记录可在原计划确认。
- 手动核对记录当时的作业状态和观察时间，再次读取原请求会返回当时的回执。在途、已核实和未取得新回执分别显示，自动巡检轮数独立计数。

本轮源码修订起点为 `5fc03c4`。[逐项诊断索引](../development/diagnostics-0.1.13.html)固定在其审计对象 `v0.1.13`，可用于追溯原消息与触发条件。[审计与改进清单](../development/diagnostics-0.1.13.md) · [修订时的定向验收](aimatterlab-0.1.13-diagnostics.md)
