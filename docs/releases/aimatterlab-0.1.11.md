# AIMatterLab 0.1.11

2026-11-18 · Windows x64 · [更新日志](../../CHANGELOG.md)

## 工作台与对话

宽屏侧栏顶部可以直接搜索命令。侧栏展开时，「新建计算」集中在侧栏，窄屏从首页进入。助手空白页列出三个可编辑的对话示例，给草稿和历史留出更多空间。布局菜单支持选择后自动收起和按 Esc 返回。

打开下拉菜单、展开会话分组、切换工作页和发送消息时有 130–160 毫秒的过渡。只有本次发送的消息会播放入场动画。恢复历史时直接显示已保存的消息，后续流式更新也不会重播这段动画。这些过渡跟随系统的「减少动态效果」设置。

## 引导中的实际操作

从引导进入工作台或配置窗口，目标控件保持高亮，旁边说明下一步操作。点击任意处或按 Esc 会收起提示，并把键盘焦点交给目标。标题栏的「返回引导」保留原步骤和已选示例。

聚焦位置随实际状态变化。计算环境页在离线时指向连接入口，连接就绪后指向发现按钮。运行记录页优先指向可打开的记录，空列表则说明当前读取状态。配置 SSH 时可以从已有连接开始，也可以新增连接。

本版包含 0.1.10-preview.guide.2 的引导与助手技能索引改动。该预览的原始验收单独记录。[预览版验收](aimatterlab-setup-guide-unreleased.md)
