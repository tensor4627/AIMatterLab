# AIMatterLab 0.1.6

2026-11-17 · Windows x64 · [更新日志](../../CHANGELOG.md)

本版改进首次打开工作台、连接 Codex、配置 API 及检测 WSL 发行版时的等待反馈。

## 首次使用

- Windows 日常使用推荐 ZIP。解压一次后双击目录中的 `AIMatterLab.exe`。单文件便携版每次解压都会先显示「正在解压 AIMatterLab」。
- 全新配置点击「连接 Codex」时，工作台先读取账号状态。未登录时自动打开账号页。登录过程中能看到正在等哪一步、已等待多久，可取消浏览器授权，失败后可查看原因并重试。
- 已登录且缺少模型缓存时，工作台读取当前账号的模型列表，用同一个 CLI 附带的数据补全匹配条目的能力信息，再核对隔离会话的实际配置。模型访问状态由真实模型调用单独验证。
- 获取模型、保存或移除服务商、验证 API 的等待提示位于触发按钮内。WSL 发行版检测有独立状态与重试入口，手动输入的发行版会保留。
