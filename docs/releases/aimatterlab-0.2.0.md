## 内置指导审阅

更新资源工具登记参考，明确 `manifest` 的来源、端口、参数向量和最小测试结构。对照「配置此资源的科学工具」和「此资源的工具与配置记录」核对审阅入口、提交后回执和资源级技能读回。运行时提示补充原 SSH 核对、会话通道和待审草稿的恢复说明。测试任务和私有站点信息只存于验收材料。

源码和包的核对范围包括主 Agent 与编写输入、计算资源和安装、任务编写与执行图、数据与查看器、分子动力学、CV 与偏置、OPES、训练、NEB，以及 37 份材料对应的科学功能目录、引擎契约和运行时提示。源码依据项目工具定义、用户授权范围和当前界面标签核对。外部工具技能的混合路由使用独立公开夹具检查共享范围。
