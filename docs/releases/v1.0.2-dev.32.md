# 1.0.2-dev.32　共享终端历史分页与读取恢复

在已运行数小时的 dev.30 桌面窗口中，SSH 面板保留了交接前的操作权提示。重新查看同一终端时，64 KiB 的历史回放又报 `terminal_unavailable`。将相同内容分两页读取成功，两页分别包含 395 和 443 块。与此同时，原作业服务仍能提交和回收实际学校作业。[dev.31 学校验收](v1.0.2-dev.31.md)

- 终端服务每页同时遵守字节额度与 512 个输出块上限。已运行的旧终端服务可能返回更多块，新桌面会验证整个响应，交付当前页，并从实际交付的末序号继续。
- SSH 面板单独报告当前终端的读取错误。原连接与 shell 在当前操作权版本下成功读取后，面板清除对应的旧读取提示。登录、写入与调整窗口大小的错误继续由各自操作报告。

验收将旧桌面的实际故障、新桌面的隔离前后端检查，以及 dev.31 worker 的实际科学作业分别记录。学校原认证窗口保持运行。关闭桌面后的学校登录恢复及升级过程中有作业在途仍为 `not_run`。

| 验证 | 结果 |
|---|---|
| Node 全量 | Windows 4430 项通过、4 项相对符号链接用例按平台跳过，0 失败。相同 4 项在 WSL 使用真实符号链接全部通过。 |
| Python worker 全量 | 在 WSL 中复核了与 dev.31 相同的 worker 和测试源码。提供只读 pyGAS 源码、SSH 配置解析和 Node 互操作环境后，888 项通过，0 跳过。 |
| 终端分页 | 修复前重现拒绝超过 512 块的合法响应；修复后 176 项相关检查通过，覆盖新旧终端服务、用户与 Agent、Unicode、缓冲区溢出和非法响应。 |
| 窗口交互 | 60 项组件检查、TypeScript、3 项浏览器交互及 3 项独立原生 Electron 交互通过。持续读错在终端顶部可见；读取恢复时，真实输入错误、右栏会话和草稿保留。 |

本轮独立包位于 `release/v1.0.2-dev.32/win-unpacked/`。1237 个应用文件与 49 个附带资源核对通过，独立配置下的成品启动、沙箱、类型化 IPC、主要页面与正常关闭检查通过。学校窗口继续使用原 dev.30 程序，旧包的终端历史读取提示仍可复现。完整日志、原生截图和发布包核对记录存放于 ignored 的 `.studio/dev31-school-live-Fy5XuG/`。
