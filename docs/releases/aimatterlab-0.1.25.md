# AIMatterLab 0.1.25

2026-11-20 · Windows x64 · [更新日志](../../CHANGELOG.md)

工作台的渲染进程退出时，桌面在原窗口加载内置页面，并在配置目录的 `renderer-exit.json` 记录最近一次退出的时间、版本、原因和退出码。短时间内再次退出时，系统对话框提供立即重试和稍后从托盘恢复两种操作。

保存的 SSH 登录配置可以继续使用。打开终端的回执延迟时，界面从连接清单查找同一次请求。打开失败时显示具体原因，并允许用户在原配置上重试。
