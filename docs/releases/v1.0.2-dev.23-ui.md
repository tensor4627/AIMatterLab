| 设置与视觉 | 外观即时预览，显示未保存状态，取消恢复已确认保存的设置；明确 GPU 编号 / 数量、MiB 与 s。提交摘要采用准备运行记录的字段。减少重复边框、统一点击区，补全主题语义变量；原参数分组、默认值、来源、缺项定位与技术详情继续可达。 |
