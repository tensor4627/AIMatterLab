# AIMatterLab 0.1.21

2026-11-19 · Windows x64 · [更新日志](../../CHANGELOG.md)

上版真实 DeepSeek 记录显示，按资源名称及 ID 发起的两次独立终端申请分别经过约 15.2 秒才返回。SSH 已认证，四个会话终端名额均可用，作业服务就绪。旧版在本地子进程创建后立即向 PTY 发出唯一一次探针，未取得远端 shell 执行回执。工具将错误概括为通道不可用，旧终端工具和提示又给出了人工交接的恢复方向。

新版会在新 shell 出现提示后验证独立终端，兼容安静启动的 shell，并限制无副作用探针的次数。用户指定资源后由当前会话向该资源申请，查询队列可选用同资源已就绪的专属服务访问。交互终端的失败会保留原工作台连接，站点要求交互、拒绝 PTY 与就绪超时分别报告。现有会话的服务访问和其他会话的终端按各自实际回执处理。[共享终端契约](../development/shared-terminal.md)
