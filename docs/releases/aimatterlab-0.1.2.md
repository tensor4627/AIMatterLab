# AIMatterLab 0.1.2 开发版验收

2026-11-14 · Windows x64 · `dev` · [更新日志](../../CHANGELOG.md)

| 范围 | 结果 | 实测内容 |
| --- | --- | --- |
| SSH 登录与人工操作 | passed | 新配置通过桌面表单直连真实 WSL OpenSSH。交互模式核对首次主机指纹，密钥模式使用已信任的主机自动登录。两种方式均从终端键盘写入并读回标记。 |
| 人工和 Agent 共用登录 | passed | 从人工终端为 Agent 另开终端，原终端保持可写。手动切换后刷新保持选中，取消待交接后可在对应终端继续输入。 |
| 对话切到规划 | passed | 在打包版先发普通消息，再勾选任务规划发第二条。两轮均通过真实 MCP 列出同一个 SSH 终端、写入不同标记并读回。模型由本地测试端驱动，桌面、CLI、MCP、SSH 均走产品入口。首次绑定任务、收回权限、跨会话拒绝和官方 DSH 适配器另有回归覆盖。 |
| 终端协议与显示 | passed | 终端与前端定向回归分别通过 293 项和 92 项，覆盖有序输入、重复请求、输出唤醒和后台服务交接。Linux OpenSSH 辅助程序 10 项、真实 Windows ConPTY 1 项通过。浏览器 8 个工具调用场景通过，含空消息穿插的连续终端调用。 |
| 任务管理与 Slurm | passed | 经桌面提交两个 300 K 真空丙氨酸 NVT 作业，核对 QoS、状态和来源会话，并从任务管理页取消排队作业。队列与部署定向测试 32 项、Linux worker 47 项通过。 |
| 4090 计算 | passed | 22 原子，1 fs 步长，100 万步。退出码 0，运行 9 分 52 秒，读回 1000 条热力学记录和 100 帧轨迹，末帧为 1 ns。 |
| 5090 计算 | not_run | 按用户要求在排队时取消。Slurm 确认运行时长为零。已核对两类节点上 GPUMD 和 GPU-Sampling 可执行文件，本次无偏 NVT 使用 GPUMD。 |
| 自定义 API 连接通知 | passed | 真实 SQLite 验证无会话 ID 的连接级通知可正常转发。服务商、协议和网关相关回归 71 项通过。 |
| Windows 包与安装入口 | passed | ZIP 与便携 EXE 从隔离配置启动，核对版本、五个工具来源及跨格式设置保存。桌面 ZIP、开发者工具包与五项 SHA-256 校验通过。单 prompt 从 dev 取得完整提交，示例安装计划通过。 |

集群验收通过测试专用 SSH 转接复用用户已登录的现场连接。桌面双登录模式的测试直接连接独立 OpenSSH 服务。现场重新输入密码或 OTP、线上付费模型调用和其他科学引擎均为 `not_run`。
