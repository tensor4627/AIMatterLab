# v0.4：字号、登录、中央任务与 SSH 集群

更新日期：2026-10-13。便携程序：release/GPU Sampling Studio 0.4.0.exe。

## 本代功能与修复

统一原先写死的界面字号，增加“最小文字字号”和独立 Agent 对话字号。说明文字、状态栏、标签、新任务卡、账户窗口、集群设置与 ECharts 标注跟随设置；编辑器和终端保留独立字号。实际桌面测试把多个原先的小字放大到 17.23 px，1100×720 无横向溢出。

修复 Codex 协议固定版本与本机实际 CLI 不匹配的问题，固定为经过本轮验证的 0.162.0-alpha.17.2 并重新生成类型。提供 ChatGPT 浏览器、设备码、API Key 登录；显示真实账户状态，接收登录完成事件后自动刷新。修复旧便携目录留下的过期 CLI 路径。Kimi / Qwen 延续官方认证方式，并共用完成状态和项目服务商关联界面。模型目录不等于访问授权，真实调用结果另行记录。[官方账户协议](https://learn.chatgpt.com/docs/app-server)。

每次 Agent 请求先建立持久化中央任务页；present_task 填入计算流程、运行参数和缺失项，支持 native plan 及各服务商工具结果。即使尚未创建 Run，也能看见参数。恢复集群任务页时先等待作业服务连接，中央参数可离线阅读。真实模块草稿关联到该页，仍由用户审阅执行；计划状态与作业状态分开。

增加完整 SSH 设置窗口：导入已有连接、内部跳转、LSF / Slurm、只读环境探测、版本化提交 Skill、只读文件根目录、文件预览与下载、交互终端和作业监控。Agent 通过结构化工具提出修改，用户保存后生效。任务先准备本机快照与批脚本，审阅后上传、提交。计算前在执行节点验证，不需要部署远程 Agent CLI。详见 [SSH 管理链路与可行性](../ssh-cluster-management.md)。
