# v0.10.0 · DeepSeek API 接入

2026-10-17。增加独立 DeepSeek 服务商，保留 Codex、Kimi 和 Qwen；不依赖 Codex app server 或新增 CLI。

## 使用

Agent 面板 → 服务商 **DeepSeek API** → **登录 / 账户** → 输入开放平台 API Key → **保存凭据并连接**。密钥由主进程通过 Electron safeStorage 加密到用户凭据目录，不写入设置、命令行或 Git。连接后实际调用官方 `https://api.deepseek.com/models` 读取模型目录，不伪造账户权限。模型目录成功与推理可用分开，完成真实回复后才标记模型调用已验证。

已知当前模型默认 `thinking.disabled` / `reasoning_effort=none`，适合优先减少思考等待；可选 low、high、max。未知模型仅使用服务默认，不冒称支持思考参数或上下文容量。没有测量或保证相对 Codex 的 TPS。协议依据 [Chat Completions](https://api-docs.deepseek.com/api/create-chat-completion/)、[模型目录](https://api-docs.deepseek.com/api/list-models/)、[思考模式与工具历史契约](https://api-docs.deepseek.com/guides/thinking_mode/)。

## 实现边界

- 主进程通过 Electron net.fetch 调用官方固定 API，使用系统网络配置；回环科学 MCP 使用独立连接及 MCP 凭据，API Key、MCP Token 和管理 Token 不互传。拒绝 HTTP 重定向。渲染器没有 Node、文件系统或任意网络接口。
- 增量解析 SSE 与函数参数；完整结束标志到达后才调用工具。错误、余额不足、限流、截断、中断如实显示，不自动重试调用或提交。
- 工具名称、结构化参数、会话绑定 task_id 与已绑定 project_id 由桥接层检查；普通对话只暴露读取接口，规划/流程/复核可以创建输入草稿。提交、验证、取消和任意 shell 工具不暴露给该模型；实际计算由桌面审阅执行链路完成。
- 工具输出沿用原生事件，填写当前流程页面、红绿参数状态及复核按钮；同一会话持续更新既有流程。复核被取消或中断时不能放行执行。
- 独立本地会话历史保存 API 所需思考字段，以满足多轮工具协议；不向界面输出这些字段。恢复仅读取已存历史，未确认工具只记录未知结果，不自动重放。无自动摘要；超出模型上下文时明确报错，需新建会话或缩短输入。
- 本次为新增 provider/history 对象，没有删除测试会话或迁移现有连接。SSH、凭据、环境、项目授权、实际运行状态保留；兄弟引擎仓库不修改。
