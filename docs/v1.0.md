# v1.0 开发与闭包验收记录

开发分支为 `codex/v1.0`，从修复后的 `e8ba66a` 开始；当前开发版本 `1.0.0-dev.1`。目标和迁移顺序见 [重组方案](development/repository-reorganization.md)，产品契约见 [spec](software-specification.md)。尚未发布正式 1.0，也未创建发布标签或推送。

## 状态与证据口径

按功能闭包记录实现、验证和剩余工作。工程检查、实际原生交互、安装包核对和科学执行分别记账；mock 和合成夹具不证明现场资源或科学结果。原始输出留在 `.studio/reorganization/v1/` 等 ignored 目录。

1.0 保留现有真实数据和公开行为。首批重组不迁移用户数据库，不改连接、凭据、环境登记、项目授权、Run ID 或生产作业。新增记录使用独立 kind 和 schema 版本；需要改变旧格式时另有版本化迁移和恢复验证。

## 后续必需闭包

- 后端工具包登记、测试重定向及流程输入输出匹配；逐步接入现有真实执行路线。
- 用户真实配置、安装/对应测试记录、执行 skill 生成与激活；旧观测不能自动升级为配置通过。
- 所有自动、手动、目录发现、MCP 和引用读取入口的 skill 封存策略，日常执行对前置指导零读取。
- 前端 feature controller、Agent provider/session/context 归位；清理经消费者审查确认无用的旧实现。
- worker 内部分域、目标目录迁移、测试入口和资源分发收尾；保留旧服务和真实任务恢复能力。
- 按受影响层完成组件、API/持久化、原生交互和最终包检查；需要实际工具执行时只选对应有界路线。
