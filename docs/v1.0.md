## 原生与分发检查

- **passed**：dev.2本地未签名目录包。复用现有Electron 44.5.1，命令级关闭依赖重建及exe元数据编辑/签名；36个关键源码/资源与工作树字节一致，完整worker清单哈希一致，必要外部资源存在，私有运行目录和worker测试未入包。核对的是当前目录包，不是正式portable发布或安装升级兼容矩阵。
- **passed**：目录包使用全新隔离profile实际启动，原生可访问性树显示app.asar中的界面、`1.0.0-dev.2`、未连接控件和禁用的发送按钮；旧生产窗口与其配置未操作。
- **failed后修正执行方式**：默认打包需要网络取得Electron而受阻；复用本地Electron后，沙箱下pnpm依赖收集仍失败。相同本地打包命令在正常执行上下文中通过。首次包检查脚本还需修正Windows路径分隔符，包内模块本已存在；这些检查错误不作为产品缺件记录。
- **blocked，未记通过**：首次Windows截图捕获超时，坐标输入缺少几何信息；可访问性读取和草稿字段赋值可观察，但不足以证明完整导航/会话行为。真实Electron DOM事件与preload/main IPC的窄验收另行记录。
- **passed**：`node scripts/native-conversation-check.mjs --out <全新.studio子目录>` 实际执行6项会话窄验收。准备阶段两次失败均保留：第一次错误假定Electron44的运行时偏好提供preload路径，第二次验收白名单漏掉既有只读worker.status；只修验收脚本，无生产修改。最终`native-conversation-c10-03/receipt.json`通过；preload绑定以真实main配置AST、源码哈希、实际bridge和IPC往返核对，运行时未报告的路径明确为null。

- 后端工具包登记、测试重定向及流程输入输出匹配；逐步接入现有真实执行路线。

- 按受影响层完成组件、API/持久化、原生交互和最终包检查；需要实际工具执行时只选对应有界路线。
