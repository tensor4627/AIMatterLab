# Agent 本地技能工作区

在普通对话说「把 skill 存到本机工作区」或「存到工作区的技能库」，Agent 使用 `scope=user` 保存到跨对话可用的个人库。指定「只用于这个项目」时，技能随项目共享。未选项目时，指定「只用于这次对话」会保存到该对话的私有目录。以上操作均可在断开 SSH 和作业服务时完成。

指定「把这套流程保存到当前计算资源的技能库」时，Agent 在本机为已交接的 SSH 资源保存一份可复用的技能。当前对话先取得该资源的访问权，桌面再核对资源身份和登录账号。名字相同的集群或账号各用自己的库。

## 保存位置

Windows 安装版默认使用所选工作区下的 `user-cache/skills/`。个人库位于 `user/<技能名>/SKILL.md`，项目和私有对话库位于 `<作用域摘要>/<技能名>/SKILL.md`。资源库位于 `resource-<资源与账号摘要>/<技能名>/SKILL.md`。技能目录回执的 `directory` 给出所查库的绝对目录。读取或写入技能后，回执的 `path` 给出该 `SKILL.md` 的绝对路径。在「设置 → 科学资源与技能 → 本地用户缓存目录」也可以查看配置。升级保留用户显式选择的目录，沿用旧默认路径的已有配置会在内容核对后复制到新默认位置。

程序内置的主 `AGENTS.md` 会在运行时填入设置实际采用的个人库绝对目录，首次安装、便携模式和自定义路径均使用同一个桌面技能服务提供的位置。保存新目录设置时，桌面端复制个人、项目、会话和资源技能并保留原件。新会话使用新位置。迁移时，如果目标库已有同名且内容不同的技能，设置会显示冲突并继续使用原目录。

## 技能来源与流程选择

| 来源 | 范围与访问方式 |
| --- | --- |
| 个人技能 | 跨对话复用。用 `project_skill_catalog`、`read_project_skill`、`write_project_skill` 并传 `scope="user"`。 |
| 项目或会话技能 | 用上述工具并传 `scope="current"`。绑定项目时随项目共享，否则仅属于该对话。 |
| 资源技能 | 用上述工具并传 `scope="resource"` 和当前对话已取得访问权的 `resource_id`。在同一资源和同一远端账号的不同对话中复用。 |
| 软件内置指南 | 位于安装包的 `resources/studio-skills/`。通过 `scientific_skill_catalog` 查功能 ID，通过 `read_scientific_skill` 按 ID 读取。 |
| 已登记的源码与工具包指南 | 按来源、版本、共享设置和当前工具选择读取。配置好的执行指南沿用所选工具和环境的绑定。 |

各技能库可各自保留同名技能。通用技能目录跳过个人、项目、会话和资源库。两份指南对同一步给出互不兼容的做法时，Agent 指出两个来源及具体差异，向用户询问采用哪套流程，并等待选择后再执行该步骤。用户的选择在已有项目与计算资源权限内生效。

资源库支持保存用户自己的操作笔记或流程技能。工具通过最小测试后，桌面根据作业服务的激活回执在同一个库写入和读回执行技能。执行技能使用 `tool-<工具名>-<12位激活摘要>` 名称，由工具配置流程发布。技能尚待写入时，在原工具配置中选择「补写执行技能」，以原测试回执和正文摘要完成保存。

## 项目级提示词

每个已绑定项目有独立的 `AGENTS.md`，位于该项目的技能库目录。首次查询当前项目技能或保存技能时创建。可直接编辑其中的项目约定，或用相对链接引用已有技能，例如 `[本项目的分析流程](../user/local-analysis/SKILL.md)`。在项目中保存个人或项目技能时，工作台会把对应文件的链接追加到该文档。要定位文件，可让当前 Agent 给出 `project_skill_catalog` 返回的 `instructions.relativePath`，从设置显示的技能缓存目录打开即可。

Agent 查询当前项目的技能目录时，读取同一项目的提示词，并按链接的名称和作用域调用技能读取工具。迁移缓存时，项目提示词和技能一起复制。工作区根目录的 `AGENTS.md` 提供总目录和使用说明。

## Agent 工具

| 用途 | 调用 |
| --- | --- |
| 查个人库 | `project_skill_catalog({"scope":"user"})` |
| 查当前项目或私有对话库 | `project_skill_catalog({})` |
| 查资源库 | `project_skill_catalog({"scope":"resource","resource_id":"ssh:<已取得访问权的资源标识>"})` |
| 读取技能 | `read_project_skill`，传入同一 `scope` 和技能名 |
| 新建或更新 | `write_project_skill`，传入同一 `scope`、`name`、`body` 和 `expected_sha256` |
| 查内置科学指导 | `scientific_skill_catalog`，再用 `read_scientific_skill` 读取匹配的条目 |

新建时传 JSON `null`，更新时传上次读取的 SHA-256。正文须包含匹配的 `name` 和一行 `description` 前置信息。服务商若显示写入确认，接受后完成保存。写入后按同一作用域读回正文与摘要。读取或写入资源技能时都要传入同一个 `resource_id`。每个库最多 64 个单文件技能，单文件最大 16 KiB。模型通过桌面端读写技能名对应的本机文件。集群上的副本需单独管理。

五种 Agent 服务商的首轮上下文都包含程序随版本提供的运行时索引。安装器在全新工作区写入目录说明，升级沿用现有的 `AGENTS.md`。运行时读取已识别的安装工作区中不超过 8 KiB 的普通 UTF-8 索引，识别已知历史默认前缀并附上用户自己的后续说明。源码版与便携版使用当前程序提供的运行时索引。[运行时 AGENTS.md](../agent/context/AGENTS.md)

助手根据用户消息查询当前项目的 `AGENTS.md`、个人库和匹配的科学指南。技能正文和更详细的参考文档按需加载。连接作业服务前，桌面也提供两个科学指南只读工具。恢复聊天时保留原消息与工具收据，需要行动时重新通过当前工具核对指导与资源。
