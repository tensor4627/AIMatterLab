# Agent 本地技能工作区

在普通对话说「把这个做法保存为本机技能，以后新聊天也能用」，Agent 会写入个人技能库。指定「只用于这个项目」时，技能随项目共享。未选项目时，指定「只用于这次对话」会保存到该对话的私有目录。以上操作均可在断开 SSH 和作业服务时完成。

## 保存位置

Windows 安装版默认使用所选工作区下的 `user-cache/skills/`。个人库位于 `user/<技能名>/SKILL.md`，项目和私有对话库位于 `<作用域摘要>/<技能名>/SKILL.md`。在「设置 → 科学资源与技能 → 本地用户缓存目录」可以查看实际路径。升级保留用户显式选择的目录，沿用旧默认路径的已有配置会在内容核对后复制到新默认位置。

保存新目录设置时，桌面端复制已有技能并保留原件。遇到同名且内容不同的技能时，显示冲突并继续使用原目录。

## 项目级提示词

每个已绑定项目有独立的 `AGENTS.md`，位于该项目的技能库目录。首次查询当前项目技能或保存技能时创建。可直接编辑其中的项目约定，或用相对链接引用已有技能，例如 `[本项目的分析流程](../user/local-analysis/SKILL.md)`。在项目中保存个人或项目技能时，工作台会把对应文件的链接追加到该文档。要定位文件，可让当前 Agent 给出 `project_skill_catalog` 返回的 `instructions.relativePath`，从设置显示的技能缓存目录打开即可。

Agent 查询当前项目的技能目录时，读取同一项目的提示词，并按链接的名称和作用域调用技能读取工具。迁移缓存时，项目提示词和技能一起复制。工作区根目录的 `AGENTS.md` 提供总目录和使用说明。

## Agent 工具

| 用途 | 调用 |
| --- | --- |
| 查个人库 | `project_skill_catalog({"scope":"user"})` |
| 查当前项目或私有对话库 | `project_skill_catalog({})` |
| 读取技能 | `read_project_skill`，传入同一 `scope` 和技能名 |
| 新建或更新 | `write_project_skill`，传入同一 `scope`、`name`、`body` 和 `expected_sha256` |
| 查内置科学指导 | `scientific_skill_catalog`，再用 `read_scientific_skill` 读取匹配的条目 |

新建时传 JSON `null`，更新时传上次读取的 SHA256。正文须包含匹配的 `name` 和一行 `description` 前置信息。服务商若显示写入确认，接受后完成保存。写入后按同一作用域读回正文与摘要。每个库最多 64 个单文件技能，单文件最大 16 KiB。模型只能通过桌面端读写技能名对应的文件。集群上的副本需单独管理。

五种 Agent 服务商的首轮上下文都包含[运行时 AGENTS.md](../agent/context/AGENTS.md)。安装版从已识别工作区根目录读取用户补充的索引，支持不超过 8 KiB 的普通 UTF-8 文件。安装时写入默认索引，升级时只迁移与 0.1.9 原版逐字节一致的旧说明。源码版与便携版使用随程序提供的运行时索引。

助手根据用户消息查询当前项目的 `AGENTS.md`、个人库和匹配的科学指南。技能正文和更详细的参考文档按需加载。连接作业服务前，桌面也提供两个科学指南只读工具。
