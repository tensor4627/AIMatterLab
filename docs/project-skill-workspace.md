# Agent 项目技能微工作区

在普通 Agent 对话中直接说“为当前项目创建一个 skill，要求……”，无需给予本机目录写权限或配置技能搜索目录。Agent 通过 `project_skill_catalog`、`write_project_skill`、`read_project_skill` 创建、发现和读回真正保存的 `SKILL.md`。程序启动时注册同一组 MCP 工具；每轮的内置指引要求先发现技能，再按当前任务读取相关正文。它不是靠外部 CLI 扫描用户主目录加载。

技能保存在程序自己的配置目录 `project-skills/<作用域摘要>/<技能名>/SKILL.md`。选定项目时按可信项目标识隔离，同一项目的后续对话可复用；未绑定项目的普通聊天使用当前对话独有空间，不会自动迁移到其他项目。重新打开程序仍从磁盘读取。修改前须读取 SHA256；过期版本会拒绝覆盖。每个作用域最多 64 个技能，每个正文最多 16 KiB，使用包含 `name` 和 `description` 的 YAML 前置信息。

这些工具只支持技能名和文本，不接受任意文件路径，不读取凭据，不执行脚本，不改变项目授权。它们在不连接科学 worker、也不交接终端的普通聊天中即可用；有 worker 时通过相同的桌面代理提供，依赖当前服务商的 MCP 工具调用能力。当前仅支持单文件技能；引用的脚本、额外资料、外部路径和自动执行不在此能力范围。

保存和读回表示文件操作成功，不代表技能里的科学方法或指令已经验证。模型是否遵循具体指令仍需结合真实任务判断。
