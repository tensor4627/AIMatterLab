For \(f(r)=[1-(r/r_0)^n]/[1-(r/r_0)^m]\) with \(0<n<m\), the removable limit at \(r_0\) is \(n/m\), and the weight is positive at every finite positive radius. ## Model and native controls

The pinned example pairs `WTMetaDProcedure` with `WTMetaDGaussianBias`. The pinned constructor order starts with `sigma, weight, scale, temp, bias_factor`. Pass these by name. Use `sigma` and `scale` in collected CV order, `weight` for the untempered hill height in eV, `temp` in K, and `bias_factor` for \(\gamma=(T+\Delta T)/T>1\). Use one-element vectors for a one-component CV. For the pure WT route the deposited height is \(w_0\exp[-V(s_j,t_j^-)/(k_BT(\gamma-1))]\), where \(V(s_j,t_j^-)\) is the accumulated bias before adding that hill. Choose \(\sigma\) from pilot fluctuations and the resolution needed between states. Use \(k_BT\) and the resulting bias forces to set a trial initial height, assess \(\gamma\) against the desired exploration, and compare the cadence with CV correlation and local relaxation. Treat pilot values as proposals with measured acceptance. [Pinned bias implementation](https://gitlab.com/tensor4627/pygas/-/blob/ba5787380181304a0e4c75578c2ecff736737e18/base/bias.py#L114), [WTMetaD method](https://doi.org/10.1103/PhysRevLett.100.020603).

Check the actual target parser and ABI. In the reviewed GPU-Sampling revision the native run line is `GASMD MODEL GAScfg.yaml [GASGaussian.txt]`. Leave out the third operand for a fresh run. It reads an existing Gaussian history when resuming the corresponding replica. Use one flat `key: value` line per GAScfg setting and confirm the active parsed values in the startup report. The parser skips lines without a colon and trims keys and values. For `cv_log_path` it also strips matching outer single or double quotes. The default path is `GASCVlog.txt`. Match `n_atoms`, `cv_size`, `neighbor_rc` and `max_neighbors` to the structure and model. `cv_storage_interval` is the deposition interval and `cv_log_interval` is the observation interval, both positive steps. Set `max_cv_nums` for the existing history plus the planned deposits and restart headroom. The reviewed driver can warn about a full buffer and still write a scheduled Gaussian record after refusing the append. Compare active history and warnings as well as output row counts. Count deposits at positive bias evaluation indices divisible by the storage interval. In the pinned ordinary single-bead run, the initial force evaluation precedes the loop and each of the \(N\) MD steps then evaluates the force. A fresh one-block run therefore includes bias indices \(0,\ldots,N\), with \(\lfloor N/p\rfloor\) deposits and \(1+\lfloor N/q\rfloor\) regular rows for deposition stride \(p\) and log stride \(q\), assuming no capacity or early-stop issue. Verify the actual evaluation schedule for the selected route and any segmented or resumed run. [Pinned force evaluation loop](https://github.com/bigd4/GPUMD/blob/bd719b98f1608e25477c63238c1f42d9a63d3bd1/src/main_sampling/run.cu#L174-L239). Use separate seeds, run directories and histories for independent replicas. For one replica per device, sum each replica's measured GPU occupancy and use the slowest concurrent replica for the ideal elapsed time. Benchmark late-history throughput and peak device memory as well as log, trajectory and restart byte rates. [Pinned configuration parser](https://github.com/bigd4/GPUMD/blob/bd719b98f1608e25477c63238c1f42d9a63d3bd1/src/main_sampling/gas-metad.cuh#L54-L123), [pinned GASMD operands](https://github.com/bigd4/GPUMD/blob/bd719b98f1608e25477c63238c1f42d9a63d3bd1/src/main_sampling/gas-metad.cuh#L188-L208), [pinned history scheduling](https://github.com/bigd4/GPUMD/blob/bd719b98f1608e25477c63238c1f42d9a63d3bd1/src/main_sampling/gas-metad.cu#L324-L383).

Pin the structure, potential and CV/driver versions and validate the real serialized artifact with the target neighbor list, output dimensions, bias forces and virial. Bias and virial have energy units of eV. Cartesian forces are in eV/Å. Deriving stress requires the actual sign convention and volume conversion. Check empty and nonempty histories where relevant and verify the chosen data format's compatibility. An explicitly selected AOTI backend requires a successful target reload in that backend. Reserve loading, installation and execution for the authorized scope.

For successive `run` blocks in the same process, the existing `GASMD` bias retains its history and evaluation counter. Declare it once because a repeated `GASMD` adds another bias to the force sum. A new process parses its own input and loads one bias anew. Start independent replicas with empty history. ## Read the right file and judge convergence

For this pure WT route, `GASGaussian.txt` has one deposition row `bias, CV...`. The leading column is the pre-deposition bias at the center, which the estimator uses to recover the actual hill height. `GASCVlog.txt` has regular observations `bias, CV..., mean_bias_force`. The leading field is bias in both files. Assign steps using the actual run segment and striding metadata. At a coincident logging/deposition step the recorded bias is from the model evaluation before the history append. Prefer the actual hill file. Recover hills from a CV log only when the stride alignment, starting row, restarts and bias phase are verified, for example by reconstructing pre-deposition bias from earlier hills. [Pinned file and phase contract](https://gitlab.com/tensor4627/pygas/-/blob/ba5787380181304a0e4c75578c2ecff736737e18/agents/skills/pygas-reweight-metad/references/reweighting-contract.md).

For the reviewed CLI use `pygas reweight MODEL.pt GASGaussian.txt fes.yaml` in each replica's analysis directory. The FES grid needs `grid_min`, `grid_max`, and `grid_bins` or `grid_num` in CV order. Base bounds on the physical domain and check the total grid size. Inspect `GASrGaussian.txt` (bias, normalization, residual bias, log weight and CVs), `GASFES.txt` and `FES.png`. Use the matching model and hill history. The CLI reads the deposition samples. For reweighting an entire observation series, align each frame to its active history. The weights are proportional to \(\exp[\beta(V(s,t)-c(t))]\), where \(\beta=(k_BT)^{-1}\). The pinned implementation computes the quasi-stationary WT normalization by two log-sum-exp operations over a uniform grid spanning the justified fixed domain \(\Omega\). Its continuum form is

\[
c(t)=\beta^{-1}\ln\frac{\int_{\Omega}\exp[\beta\gamma V(s,t)/(\gamma-1)]\,ds}{\int_{\Omega}\exp[\beta V(s,t)/(\gamma-1)]\,ds}.
\]

Use the physically justified CV domain for normalization and reserve common sampled support for comparisons. The default uses the active history before the current deposition. Recheck the estimator if another bias is present. [Pinned normalization](https://gitlab.com/tensor4627/pygas/-/blob/ba5787380181304a0e4c75578c2ecff736737e18/base/analysis.py#L797-L807). For direct sum-hills apply \(F\simeq-\gamma V/(\gamma-1)+C\) to the unscaled converged WT bias on supported regions. The reported FES has already undergone its estimator's conversion. [Pinned analysis implementation](https://gitlab.com/tensor4627/pygas/-/blob/ba5787380181304a0e4c75578c2ecff736737e18/base/analysis.py#L103), [time-dependent normalization](https://doi.org/10.1021/jp504920s).

Use fixed-grid time prefixes and blocks, supported-bin stability, effective sample size, revisits and independent replicas to assess convergence and uncertainty. Align additive constants on common sampled support. Disjoint basins or replicas have an undetermined relative offset, even when a curve looks smooth. The hill count sets the history budget. Convergence depends on visits across the relevant support and slow degrees of freedom, including possible hidden barriers. The effective temperature \(\gamma T\) describes the asymptotic CV marginal. The physical thermostat still operates at \(T\). Residence times describe the biased trajectory. Rate estimates require a separate kinetic method and checks of its assumptions.
