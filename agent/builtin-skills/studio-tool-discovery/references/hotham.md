# HotHam (Hot-Ham) on an AIMatterLab target

HotHam learns electronic Hamiltonians for atomic structures. A localized atomic-orbital basis (LCAO) or an orthogonal tight-binding representation (OrthTB) determines the training targets. The supplied LCAO inference example predicts matrices and uses them to reconstruct bands. HotPP is a separate interatomic-potential tool. AIMatterLab lists the HotHam source and its integration declaration. Its distributed worker engine catalog has no built-in HotHam adapter. An individual compute resource can acquire a verified tool configuration for a particular function.
