# HotHam (Hot-Ham) on an AIMatterLab target

HotHam learns electronic Hamiltonians for atomic structures. The stock nonmagnetic LCAO model learns $H(R)$, with the matrix-element loss against DFT $H(R)$ equal to RMSE plus MAE. The overlap $S(R)$ comes from the matched electronic-structure inputs. In the LCAO exporter, `h_pred` writes model Hamiltonians, `h_ref` writes supplied reference Hamiltonians when present, and `olp` writes the supplied overlap in the output basis. Assess overlap provenance and numerical conditioning. Use Hamiltonian and derived band errors to assess this model. Orthogonal tight binding uses a different representation. HotPP fits interatomic potentials. ## Reconstruct nonorthogonal spin-1 bands from existing matrices

Other file layouts need a checked conversion with the same orbital order, translation convention and units. The converter uses Ry for ABACUS Hamiltonian input and Hartree for OpenMX text, converts internally to eV and the inference writer emits Hamiltonian CSR in Ry. The diagonalizer converts that CSR from Ry to eV. Overlap is dimensionless. Preserve the actual model/DFT reference and any energy shift. ## Check scientific accuracy on untouched families

Report matrix MAE/RMSE in eV and large errors by distance, on-site versus hopping block and held-out family. Check translation-pair symmetry and loss of reference matrix weight at the cutoff. Verify the exported overlap against the supplied DFT/basis convention and check its spectrum after folding.

Compare eigenvalues at identical k points and occupations. Keep a common physical energy zero when available. A documented VBM reference for insulators can support a shape-only comparison. For a single fitted offset, define $\Delta=\operatorname{mean}(\epsilon_{\mathrm{ref}}-\epsilon_{\mathrm{pred}})$ on matched development levels for a squared-error fit. Apply $\epsilon_{\mathrm{aligned}}=\epsilon_{\mathrm{pred}}+\Delta$. A prediction above the reference must move down with a negative $\Delta$. From $Hc=\epsilon Sc$, the same uniform shift in the nonorthogonal matrix representation is $H(R)\to H(R)+\Delta S(R)$ for every translation, including off-site overlap. It preserves each energy spacing and the gap.

Use development families to choose cutoffs, fit any calibration offset or scale, and set tolerances with DFT and solver convergence in view. Freeze the model, alignment rule, fitted values, evaluation window and tolerances before evaluating independent held-out families. Report raw and aligned near-edge MAE/RMSE, maximum error, the applied offset, VBM/CBM locations and gap errors. Use an adequately converged Brillouin-zone mesh for the fundamental gap since extrema can lie off the path. For the supplied inference case, use its own dataset, model and settings. It checks parsing, shapes, outputs and finiteness. Physical accuracy requires the separate held-out comparison.
