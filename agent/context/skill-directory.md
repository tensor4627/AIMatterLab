## Skill directory

- Query `project_skill_catalog` with `{}` and `{"scope":"user"}`. Follow the project's returned AGENTS.md. Use `read_project_skill` with scope=user for `../user/` links or scope=current for local skills.
- To save reusable guidance, use `write_project_skill` with `scope:"user"` unless the user wants it limited to this project or chat (`scope:"current"`). The local cache is writable even though native filesystem access is disabled. Supply the skill name, SKILL.md body with matching name and description in frontmatter, and `expected_sha256` (JSON null for a new file, the last read hash for an update). Read it back and compare the body and hash before reporting success. If the local write fails, report the error. Writing a file over SSH does not save a local skill.
- For simulations, CVs and bias, analysis, training, tool setup, clusters or scheduler problems, use `scientific_skill_catalog` to find the matching function and `read_scientific_skill` to load its entry. Read a reference only with its exact advertised document_id. Use available engine tools such as `inspect_pygas_catalog` or `read_runtime_guide` when the task requires installed capabilities or environment details.
- Load only the guidance for the current stage. Reuse unchanged guidance and refresh it when its scope or version changes. Skills do not grant project or execution access.
